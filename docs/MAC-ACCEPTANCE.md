# Beta 3a 宽屏与主题复核

1. 解压完整源码到 `Hermes-macOS-beta-3a` 新目录，运行 `Run-Hermes.command`；帮助页版本为 `1.0.0-beta.3a`。现有 JDK 21 可继续使用。
2. 将窗口拉宽，收起文件栏，检查首页欢迎区与人物、对话和产物分区；内容不应随窗口无限拉开，摘要不应露出内部提示标记。
3. 任务中心分别查看无待处理、一个完成任务和多个运行任务。三列应对齐、显示数量；审批和澄清可点击查看详情，操作仍作用于原任务。
4. 切换三套皮肤，特别检查玻璃主题的左侧栏和主题卡片。名称、说明和缩略图应完整，鼠标点击不应产生厚重灰框。
5. 在较小窗口滚动设置页至“保存资料”，再切换其他设置项；检查 Retina 下图标、卡片边缘和文字可读性。
6. 从设置或首页点击文件图标，确认返回当前聊天并展开右侧文件栏；未发送文字、文档编辑与滚动操作保持正常。

# Beta 3 界面复测

1. 关闭旧版，解压完整源码到 `Hermes-macOS-beta-3` 新目录，双击 `Run-Hermes.command`。设置的帮助页应显示 `1.0.0-beta.3`。不要只复制一个脚本到旧目录。
2. 检查左侧为图标栏，底部只有一个设置入口。悬停等待名称提示，Tab 切换可见焦点。
3. 在聊天中输入未发送内容，切换右侧目录、搜索文件名、收起／展开文件栏，确认会话和输入仍保留；重启后确认侧栏状态保留。
4. 打开文档编辑后切换另一个文件或返回聊天，再次打开原文档，确认最新修改保留；另检查本机草稿、保存、下载和来源对话。
5. 切换三套皮肤，分别检查面板边界、消息署名、圆角、纸张纹理与半透明层次；浅色／深色都应清晰可读。
6. 在 1160×760 与较大窗口检查输入区、文件栏、运行中停止／排队／追加按钮。滚到历史消息时，“跳到底部”应在输入区上方，不盖住消息；点击回到最新回复。
7. 鼠标经过筛选、复制／朗读、图标和菜单：不再出现通用灰色矩形，保留有用途的文字或轮廓反馈。
8. 打开命令、语音、头像、定时任务、未保存文档提示与服务商弹窗，确认随当前主题显示、内容可滚动、Esc 可关闭。

9. 检查添加附件／选择头像和另存文档使用 macOS 文件窗口；取消不写入，覆盖现有文件遵循系统确认。

# Beta 2 登录复测

1. 解压完整 Beta 2 到新目录，用 `Run-Hermes.command` 运行，或用 `Package-macOS.command` 打包。登录页底部应显示 `1.0.0-beta.2`。
2. 填写与网页登录完全相同的网关地址（含端口）、用户名和密码。点击“显示”核对输入，提交时会自动恢复遮挡。
3. 连接成功后测试会话读取；退出应用再打开，检查已有登录状态恢复。
4. 若仍失败，关闭提示框，点击“复制登录诊断”并提供诊断文字。无需提供密码、Cookie 或令牌。请同时说明浏览器是重新输入账密登录成功，还是直接沿用已登录的页面。
5. 新入口不运行测试；需要完整回归与打包时使用 `Build-macOS.command`。

# Mac 功能验收

基础框架已经由用户运行。本表用于验证本轮新增能力。建议先使用普通测试会话、测试文档和临时定时任务。

## 会话与恢复

1. 运行 Run-Hermes.command，确认旧登录／称呼可以读取；切换 Profile，检查项目与会话相互隔离。
2. 同时运行两个会话，检查回复、工具进度、追加要求和停止都路由到自己的会话。
3. 在草稿中放入文字、图片、文本附件，关闭应用再打开，应完整恢复。
4. 任务运行时排队两条消息；正常完成应逐条发送。运行中关闭应用再打开，应先恢复结果，队列等点击“继续发送队列”才继续。
5. 任务运行时断网再恢复，确认没有重复提交。两次发送相同问题时不能把旧答案判成新任务完成。
6. 试用会话搜索、命中定位、日期筛选、归档／恢复、提示词片段和命令。会审依赖实际 MoA／委派能力。

## 文件与任务

1. 编辑 Markdown 的最后几个字，立即按 ⌘ S，检查中文输入法组合输入和焦点切换；再测试源码模式和复杂 Markdown。
2. 打开两份文档，分别编辑并切换标签；关闭应用后从“文件 → 本机草稿”继续，两份内容应分别保留。
3. 在另一端修改同一文件，再从桌面保存，应该提示远端内容变化而不是直接覆盖。
4. 预览图片、多页 PDF、静态 HTML；测试下载、复制路径、来源跳转和添加到对话。
5. 测试审批和单选／多选澄清。重复点击不能重复回答；重启后仍可查看待处理记录。
6. 临时创建定时任务，核对服务器时区，验证详情、编辑、暂停／恢复、立即运行和删除。

## 语音与系统能力

1. 首次录音允许麦克风访问；单次录音结束后确认文字回填。
2. 进入连续语音，在安静与有风扇声的环境各说一句，确认自动判断停顿；测试中途打断、关闭窗口、回复朗读后重新聆听。
3. 录音识别过程中断网，之后在语音设置的录音记录中重试。已经回填的同一录音不应再次自动重复追加。
4. 录音后切换会话或 Profile，结果应保留在原会话，不得进入新聊天。
5. 朗读长回复和中文内容，检查分段、语速和系统回退。系统识别只在已编译 HermesSpeech 时可选。
6. 将应用放到后台等待回复和审批通知；检查通知开关、声音和 Dock 未读标记。
7. 更换两种头像、切换主题和中英文，重启检查偏好。拖动窗口调整尺寸，检查下次恢复。

## 打包与真实网关

在 Mac 上运行 Build-macOS.command，生成 DMG，拖入 Applications 再测试登录、钥匙串、麦克风和系统识别。开发 Java 进程与安装后的应用可能需要分别授权。

模型、记忆、语音、Skill／工具集／MCP 设置请与手机版比对。Agent 更新会改动服务器，仅在确认需要更新、没有运行任务时通过界面确认执行。

报告问题时提供 Mac 芯片、macOS 版本、启动方式、复现步骤和终端错误。不要贴密码、Cookie 或 API Key。应用不会自动上传诊断日志。
