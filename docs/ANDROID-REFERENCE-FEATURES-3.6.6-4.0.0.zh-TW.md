# 3.6.6 → 4.0.0 新功能

當前功能的使用方法；歷史版本逐項變化請看更新日誌。

### 首次使用：連線自己的 9119 閘道

1. 首次開啟先閱讀三步說明，再設定本機顯示的暱稱和頭像。已有使用者升級保留設定，不會被要求重新配置。
2. 在執行 Hermes Agent 的伺服器或電腦上啟用遠端閘道，通常監聽 9119，並設定閘道使用者名稱和密碼。手機需能訪問該伺服器。
3. 連線頁填寫 http://服务器IP:9119；如果已有 HTTPS 反向代理，填寫完整 HTTPS 位址。不要填 localhost，也不要自行追加 /api 或 /v1。
4. 驗證並連線後即可聊天。連線頁或“我的 → 使用說明 → 30 秒上手與 9119 連線”可以重看說明。

4.0.0 新增。App 是移動終端，不會在手機上安裝完整 Hermes Agent；區域網或可信 VPN 可用 HTTP，公網建議 HTTPS。

### 兩種首頁：先簡潔，再按需深入

1. 新使用者預設進入簡潔首頁。用“跟我說”聊天，在“回看”“任務”“檔案”繼續日常操作，不需要配置整理功能。
2. 想集中檢視待辦和近期進展時，開啟首頁齒輪，切換到“深度助理”。
3. 首頁設定用模式卡片和狀態面板說明當前配置；按提示完成首次整理。已有首頁內容時，首次整理會顯示已完成。
4. 可以隨時切回簡潔首頁。已配置的伺服器早晚任務不會因此暫停，需要時到“任務”管理。

3.8.4–3.9.3 完善。首頁人物現為一段約 15 秒的本機迴圈動畫；開啟“減少動態效果”後顯示靜態形象。

### 處理事項：自然聊天，完成後自動核對

1. 點開首頁事項，先看背景和詳情；可以“聊聊這件事”，也可以提交卡片提供的快捷回應。
2. 在對話中直接說明最新進展。卡片相關對話結束後，App 會在後臺請求核對，不必每次回首頁手動重新整理。
3. 收到建議或討論方案不會直接把卡片標為完成。狀態以伺服器儲存的實際結果為準；普通聊天的進展也可用首頁重新整理合併。
4. 處理需要授權、澄清或結果核對時，進入“任務”或“檢視處理”繼續，不要重複傳送同一項操作。

3.7.x–3.8.7 新增並完善。首頁資料和任務處理分開核對，收到任務不等於已經完成。

### 看清變化：新增、完成與最近核對

1. 首頁成功同步後，會提示新增事項和已完成事項；最近完成的內容留有記錄，便於確認結果。
2. 提交簡簡訊息後，先看到送達或處理中的反饋，隨後再顯示伺服器核對出的實際變化。
3. 區分“內容更新時間”和“最近核對”：定時任務正常執行但沒有新內容時，內容時間可能不變。
4. 卡片按結論、背景和指標組織內容。統計數字如有範圍、時間或口徑說明，可在詳情中一起檢視。

3.8.9–3.9.2 新增。時間和變化提示基於同步結果，不會為了顯示“有更新”而改寫伺服器資料。

### 一次配置：早晚整理與檔案收納

1. 在首頁齒輪裡檢視首次整理、早晚整理和檔案收納的狀態，只操作尚未完成或需要調整的專案。
2. 早晚整理設定時間和時區後，由伺服器按計劃執行；以後只有改變安排時才需要重新配置。
3. 首頁 JSON、鎖檔案和快照統一放在工作區 .hermes-app/today/。舊版使用者按“檔案收納”遷移一次，業務檔案仍留在原處。
4. 如需應用新的卡片內容規範，開啟維護工具中的“更新整理規則”；保留已有整理時間與啟用狀態。

3.7.x–3.9.3 完善。安裝 App 更新不會自行修改伺服器 Cron；執行記錄與故障請在“任務”中核對。

### 任務與授權：集中檢視，減少對話干擾

1. 自動整理、卡片處理等後臺工作集中在“任務”檢視，手機“回看”主要保留你主動開始的對話。
2. 需要批准或補充資訊時開啟對應任務；同一項授權在其他端處理後，可重新核對伺服器狀態。
3. 遇到執行中斷或結果待核對，先檢視已有進展，再選擇繼續未完成部分或核對結果。

3.8.x 完善。臨時任務只在手機對話列表中隱藏，伺服器和 PC 記錄仍保留；當前不會自動銷燬伺服器端對話。

### 對話更順手：複製、朗讀、重新命名與恢復

1. 回答完成後可複製完整正文或點“朗讀”。語音設定可分別選擇識別語言和朗讀方式。
2. 在“回看”長按對話，選擇“重新命名”，手動輸入名稱並儲存，不再為改名呼叫 AI。
3. 將手機文字、連結或檔案分享給 Hermes，確認後傳送；取消或處理過的分享不會因重新開啟 App 重複彈出。
4. 網路中斷後 App 會嘗試恢復對話狀態。結果未確認時先檢視已有回覆，避免重複傳送；連線頁可檢視診斷。

3.6.6 起完善語言、複製與朗讀；3.8.7 加入手動改名，3.8.9 修復連續提問恢復及舊分享重複彈窗。

### 端側語音：識別與朗讀可以分別選擇

1. 開啟“我的 → 設定 → 語音”，在“手機端側語音”按需下載 SenseVoice 識別包或 Kokoro 朗讀包。頁面顯示本版的下載來源。
2. 下載支援暫停續傳和校驗；下載完成後，手動將“識別方式”或“朗讀方式”切換為“手機端側模型”。
3. 兩項可以獨立選擇，例如手機本機識別搭配 Hermes 伺服器端朗讀。也可以繼續使用系統語音或原來的伺服器端配置。
4. 本機識別失敗會保留錄音，按提示重試或明確選擇伺服器端，不會悄悄上傳原始錄音。移除語音包可釋放手機空間。

3.9.4–3.9.6 新增並修復端側朗讀相容性。當前端側包需相容的 64 位 ARM 裝置；不支援的手機仍可用系統或雲端語音。對話模型仍在伺服器執行。

### 連續語音：分句播報與打斷

1. 在語音設定開啟自動朗讀和連續對話，再從對話右上角“⋯ → 連續語音”進入。
2. 回答形成完整短句後即可開始朗讀，後面的文字繼續生成。可以調整停頓時長和本機發音人。
3. 點按打斷會停止上一輪播報並繼續聽；耳機開口打斷是可選試用，外放使用點按更穩定。
4. “語音快速回答”會請求關閉本輪深度思考，實際速度仍取決於閘道、模型和網路。切後臺會暫停錄音與播報。

3.9.4 新增。端側語音降低對伺服器識別與合成的依賴，不代表所有手機都能達到即時通話延遲。

### 4.0.0 兩個版本：功能相同，下載來源不同

1. 在“我的 → 關於”或語音包下載區域確認當前是 GitHub 版還是 OSS 加速版。
2. GitHub 版從模型專案的 GitHub Releases 下載 STT/TTS，並從本 App 的 GitHub Releases 檢查更新；OSS 版使用維護者配置的下載服務。
3. 兩版使用相同的模型版本、校驗值和功能。覆蓋安裝相同包名、相同簽名的版本會保留配置和已安裝語音包。
4. 應用內更新只接受當前渠道的安裝包。下載完成後仍需通過 Android 系統安裝介面確認，不會靜默安裝。

4.0.0 新增。無需為了升級重新配置伺服器、首頁或早晚整理。
