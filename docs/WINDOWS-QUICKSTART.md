# Hermes Windows 1.8.2

在右下角系统托盘右键 Hermes → 退出 Hermes，然后运行 `Hermes-Windows-1.8.2-Setup.exe`，使用原安装目录即可升级。无需另装 Java。用户配置、头像和草稿继续保存在 `%LOCALAPPDATA%\HermesDesktop`。

便携版完整解压到新目录后运行 `Hermes.exe`。请使用包内完整运行环境和启动文件，不要只覆盖主 JAR，或混用旧依赖。1.8.2 已合并启动修复。

- **悬浮球：**设置 → 桌面助手，可开关悬浮球。单击提问、双击框选截图，拖入文件可添加附件。按住左键约 0.55 秒开始说话，松开后识别并发送；回复后等待下一次按住。右键菜单中的“连续语音”仍可持续对话。
- **后台：**关闭主窗口后程序留在系统托盘，正在运行的任务继续执行；托盘右键 → 退出 Hermes，才会完整退出。
- **供应商：**设置 → 模型供应商。可填写常用 API Key，也可添加自定义端点。已保存的密钥不回显，编辑自定义供应商时留空保留密钥。
- **头像：**设置 → 外观与账户 → 我的头像。用户消息右侧显示该头像；助理头像独立配置。
- **文件：**点击输入框的添加文件，或拖入文件、复制文件后 Ctrl+V 粘贴。先看到附件条目，再发送。失败会提示原因并保留草稿。每次最多 10 个，图片最多 8 MB，其他文件最多 12 MB。
- **Markdown：**文件页支持阅读、编辑与双栏；双栏工具条可切换同步/独立滚动。Ctrl+F 查找，Ctrl+H 替换。
- **HTML：**静态预览，支持工作空间相对图片和 CSS。加载时可切到源码；网页脚本和动画不执行。
- **其他预览：**图片可缩放、平移、旋转；PDF/PPT 可跳页和查看缩略图；Excel 支持工作表、分页和合并单元格；Word 支持段落、图片与表格。

Office 为本地只读预览，不保证复杂分页、字体、图表和动画与 Microsoft Office 一致。需要原生效果时可下载到本机打开。启动失败时运行 `Diagnose-Hermes.bat`，日志位于 `%LOCALAPPDATA%\HermesDesktop\logs`。

安装包尚未代码签名。自动化在 Linux 执行；Windows 原生交互和 JavaFX 嵌入的验证范围见 `WINDOWS-VALIDATION.md`。
