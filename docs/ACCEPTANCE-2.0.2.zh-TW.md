# Hermes Desktop 2.0.2 驗收

自動化覆蓋：跨裝置新訊息、舊訊息數量/分頁、前臺定時同步、視窗恢復、手動重新整理、載入歷史後的同步、失敗保留與重試、草稿/附件保留、流式回覆併發保護、預設啟動工作台、模組進入/返回、8 個最近對話、未讀範圍、通知對話路由與賬號隔離、JNA Blocks 回撥引數。

實際桌面介面截圖位於 docs/previews/desktop-2.0.2。測試報告和構建校驗儲存在 docs/validation。

Mac 本機驗收步驟：

1. 解壓並將 Hermes.app 放入“應用程式”，退出舊程序後開啟，確認先進入工作台。
2. 開啟“值得留意的事”，再返回工作台；確認沒有兩種首頁模式切換。
3. 在兩端開啟同一工作空間、同一對話，手機傳送一輪；電腦保持前臺或切回視窗，核對新增訊息出現。
4. 在未檢視的對話中產生新回覆，檢查列表“未讀”和側欄數字；開啟併成功讀取後應清除。
5. 在設定中傳送測試通知，允許 Hermes 的系統通知；點選新產生的通知應開啟 Hermes。後臺對話回覆通知應開啟對應對話。舊版已經發出的 AppleScript 通知無法被新版改寫，請用新版產生的通知驗證。

當前 Linux 構建環境不能操作 Mac 通知中心，原生通知展示/點選沒有真機驗收記錄。Windows 原生啟動也需對應系統驗證。
