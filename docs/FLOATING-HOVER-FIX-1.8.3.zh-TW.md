# 1.8.3 懸浮球懸停防閃爍修訂（2026-09-16）

本包已將修訂整合到完整原始碼，無需手動貼上補丁。版本號保持 1.8.3。

## 修改
- 保留固定 84×84 視窗，新增固定低透明度繪製底層，避免滑鼠命中區域跟隨圖示透明畫素變化。
- 懸停狀態按螢幕座標和固定視窗邊界判斷，不再直接相信原生 mouseEntered/mouseExited。
- 移除可能遮擋懸浮球的系統 Tooltip，保留無障礙操作描述。
- 懸停穩定後低頻檢查滑鼠位置，隱藏/截圖時停止動畫並清理懸停狀態。
- 單擊、雙擊、長按語音、拖動和右鍵選單的手勢分發保持原實現。
