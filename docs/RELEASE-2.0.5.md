# Hermes Desktop 2.0.5 · 文件定位修复

有些回复只写文件名，实际文件却保存在工作目录的子目录中。2.0.3 修复了相对路径截断，但没有覆盖这种缺少目录的链接。

- 点击仅含文件名的链接或卡片时，优先采用原回复中的完整位置；直接读取失败后，在来源会话的工作目录及子目录中查找。
- 完整查找后只有一个匹配文件才自动打开；多个同名文件显示完整路径供选择。
- 超时、权限不足或目录数量超过限制时，说明查找未完成，不把不完整结果当成唯一匹配，也不直接声称文件已删除。
- 记住实际读取成功的路径，后续点击、刷新文件索引和重启后继续使用；文件移动后可在原范围重新查找。
- 增加粘贴服务器完整路径打开和复制排查信息。长候选列表可滚动，底部按钮固定可见。

查找只使用现有文件读取接口，最多 128 个目录、20,000 个项目、约 10 秒，不执行服务器命令，不修改文件或对话。目录过大时可直接粘贴完整路径。
