# Hermes Desktop 2.0.0 · 驗收版

與 Android 4.0.0 共用首頁協議、伺服器記錄和事項操作回執。預設簡潔首頁，可切換深入首頁檢視關注、待收尾和提醒。

- 支援 6 種卡片佈局、20 類互動、事項聊天及結束後的增量同步。
- 首頁設定支援早晚整理、實際 Cron 核對、舊版儲存遷移；僅最佳化規則時保留原任務安排。
- 後臺維護記錄歸入首頁任務，全部對話入口保留；新增、最近完成和讀取順序獨立維護。
- 修復新建空對話首條訊息、舊執行 ID、閘道就緒競態、讀響應斷流、心跳與休眠恢復。
- 授權回答前同步伺服器快照；修復跨端處理後的舊請求殘留。模型切換相容 lazy 後設資料，明確狀態以伺服器回讀為準。
- 手工對話名稱完整保留，允許 1–120 字元。
- 語音識別和朗讀獨立設定；支援完整句子提前朗讀、下一句預取、打斷後恢復聆聽。
- 可分別下載 SenseVoice 和 Kokoro，支援續傳、SHA-256 校驗和移除；錄音恢復保留原識別引擎。
- 修復 WAV 錄音錯誤標記為 MP4；補充離線連線指南及本機/遠端位址說明。

OSS 下載與更新源按要求留到最後處理。本驗收版仍使用 GitHub 官方釋出下載。

本次在 Linux 構建環境完成自動化與離屏介面檢查。Windows/macOS 安裝、系統麥克風/音色、休眠喚醒及真實 Hermes 閘道聯調仍需實機驗收；不得將這些專案視為已通過。
