## 最省事的使用方式

1. 完整解压 `Hermes-macOS-arm64-1.8.3-BuildKit.zip`。
2. 双击解压目录里的 `Build-Mac-App.command`。
3. 等待完成，Finder 会自动打开结果文件夹。里面同时有 `Hermes.app` 和 `Hermes-macOS-arm64-1.8.3.dmg`。
4. 退出正在运行的旧版 Hermes，打开 DMG，把 Hermes 拖入 Applications。之后从“应用程序”打开。

这份文件是**在 Mac 本机生成应用的打包文件**，不是已经生成好的 DMG。包括已编译程序、Apple Silicon 原生依赖、官方 JDK 21 和文件校验表。生成过程不需要联网下载开发依赖，不需要 Homebrew，也不需要另行安装 Java。

构建过程不会覆盖已有安装或删除个人配置。每次结果保存在独立的 `output/Hermes-1.8.3-时间/` 文件夹。

如果双击没有启动，可以打开“终端”，输入 `bash` 和一个空格，再把 `Build-Mac-App.command` 拖入终端，按回车。

## 日常使用

- 关闭主窗口后，Hermes 继续驻留；点击 Dock 图标或菜单栏 Hermes 图标重新打开。
- 菜单栏、“窗口”菜单和设置均可开启或关闭桌面悬浮球。
- 悬浮球单击提问、双击截图、长按说话后松开发送；右键、触控板辅助点按或 Control＋点击打开菜单；点桌面其他位置或按 Esc 关闭菜单。
- 图片附件点击名称预览，单独的 × 删除。Command＋滚轮缩放，双击切换原始大小。
- 截图前按系统提示允许屏幕录制。权限不足会停止本次截图并提示；允许后重试，必要时退出并重开 Hermes。
- 录音需要麦克风权限。服务器识别可直接使用；若 Mac 已安装 Apple Command Line Tools，脚本还会构建可选的系统识别组件。没有该组件不影响服务器识别和系统朗读。
- 从应用菜单选择“退出 Hermes”或使用 Command＋Q 正常退出，会经过保存草稿的流程。

## 签名与验证

生成脚本会检查 JDK 与程序字节、Apple Silicon 架构、应用标识和版本、运行环境模块，并使用本机 ad-hoc 签名及 `codesign` / `hdiutil` 验证。它没有进行 Apple Developer ID 签名或公证，不作为已公证的公开发行包。

随包 JDK 解压后，脚本仅清理经校验的临时构建目录和生成应用上的下载隔离标记，不关闭系统 Gatekeeper、不改变系统全局安全设置。

此轮编译和回归测试运行于 Linux；Mac 菜单栏、Dock、钥匙串、屏幕/麦克风授权及最终 app/DMG 仍需在你的 Mac 上验证。`validation/` 保存本次自动化与打包文件检查记录。

若生成失败，日志位于 `build/logs/`；请保留并提供最新的 `build-*.log`。生成成功后可删除整个打包文件夹，安装后的 Hermes 已带独立运行环境。

## 个人数据

沿用 `~/Library/Application Support/HermesDesktop` 和原钥匙串服务，不清空旧 Mac 版的账号、草稿与头像。Windows 的加密配置受 Windows 用户保护，不能直接当作 Mac 配置复制；在 Mac 上登录同一网关获取远端会话。
