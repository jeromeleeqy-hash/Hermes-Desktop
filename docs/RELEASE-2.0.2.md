# Hermes Desktop 2.0.2

## 会话同步与未读

- 读取最新消息前核对服务器消息数量，避免长对话按旧偏移量一直读到旧消息。
- 停留聊天页时每 5 秒核对消息；返回窗口和手动刷新立即核对。前台会话列表每 15 秒刷新。
- 保留已加载的历史、输入草稿和附件；旧请求不能覆盖正在生成的回复，失败时保留已显示内容并允许恢复。
- 未读数量按当前工作空间、项目和普通会话统计，排除隐藏后台任务和已移除会话。列表显示明确的“未读”标记；成功读到消息后清除。
- 保存已读消息数量，用于识别其他设备新增的消息。

## 桌面工作台与导航

- 普通启动默认进入简洁工作台，同时保留上次对话和草稿。
- “值得留意的事”是工作台中的独立模块，点击查看全部，明确返回工作台。
- 去掉桌面端两种首页模式切换；事项整理、同步、早晚安排放在模块内部。
- 侧栏最近会话从 4 个增加到 8 个，置顶优先，空间不足时滚动。

## macOS 通知

- 使用 Hermes.app 自身的 UserNotifications 通知中心，不再调用 osascript。
- 点击回复或待确认通知打开 Hermes 和对应会话；首页通知打开工作台。
- 跳转保留工作空间与会话 ID，支持启动连接完成后继续跳转，并防止旧账号通知跳入其他连接。
- 首次发送时由 macOS 请求 Hermes 通知权限。

继承 2.0.1 的确认面板布局、取消逐条“已发送”提示、卡片排版和本地 TTS/STT 修复。

构建环境为 Linux；Mac 原生通知展示/点击和 Windows 原生运行需在对应系统验收，不能由跨平台自动化代替。
