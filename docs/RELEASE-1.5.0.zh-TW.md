# Hermes Windows 1.5.0 · 體驗細化

- 視窗：雙擊改為識別完整點選，拖曳經過閾值才交給系統；Windows 11 使用 DWM 圓角，Windows 10 提供原生視窗形狀回退，最大化恢復直角。記住普通視窗大小。
- 圖示：清理應用圖示的黑色不透明角，生成多尺寸 ICO；控制元件改用 Microsoft Fluent System Icons 的原版 20/24px Regular 與 Filled 資源，共 160 個。
- 選單與彈窗：統一 10px／12px 圓角、緊湊行距、中性圖示、分組間距、輕邊框、懸停反饋和主按鈕。工作空間、模型、檔案、編輯、右鍵選單採用同一套規則。
- 工作台：獨立有限高度滾動容器和可見捲軸，小視窗和 150% 縮放可滾動到底部；增加輸入框上方的滾輪迴歸。
- 主題：用真實介面縮圖替換抽象線框，並保持正確比例。
- Markdown：預覽／編輯／雙欄、語法著色、行號、搜尋、目錄、選區格式化、撤銷重做、修改對比、閱讀字級、任務清單、程式碼複製和草稿提示。窄視窗目錄改用選單。保留基礎 Markdown 排版編輯入口。
- 中文編輯：輸入法的一次組詞作為一條撤銷記錄；編輯不經過 HTML 轉換，原始文本保留。
- 動效：頁面和提示淡入、懸停與按下漸變、開關滑動、摺疊展開過渡；遵循減少動效設定。
- 分發：新增 NSIS 安裝包和原生啟動器，支援當前使用者安裝、開始選單、可選桌面快捷方式和解除安裝保留使用者資料。

這是用戶端更新，繼續使用現有 Hermes 閘道與賬戶。安裝包與便攜版來自同一份已校驗的 Windows 應用和執行環境。

驗證記錄及尚未在真機驗證的專案見 WINDOWS-VALIDATION.md。
