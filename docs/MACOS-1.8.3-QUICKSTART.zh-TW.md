## 最省事的使用方式

1. 完整解壓 `Hermes-macOS-arm64-1.8.3-BuildKit.zip`。
2. 雙擊解壓目錄裡的 `Build-Mac-App.command`。
3. 等待完成，Finder 會自動開啟結果資料夾。裡面同時有 `Hermes.app` 和 `Hermes-macOS-arm64-1.8.3.dmg`。
4. 退出正在執行的舊版 Hermes，開啟 DMG，把 Hermes 拖入 Applications。之後從“應用程式”開啟。

這份檔案是**在 Mac 本機生成應用的打包檔案**，不是已經生成好的 DMG。包括已編譯程式、Apple Silicon 原生依賴、官方 JDK 21 和檔案校驗表。生成過程不需要聯網下載開發依賴，不需要 Homebrew，也不需要另行安裝 Java。

構建過程不會覆蓋已有安裝或刪除個人配置。每次結果儲存在獨立的 `output/Hermes-1.8.3-时间/` 資料夾。

如果雙擊沒有啟動，可以開啟“終端”，輸入 `bash` 和一個空格，再把 `Build-Mac-App.command` 拖入終端，按回車。

## 日常使用

- 關閉主視窗後，Hermes 繼續駐留；點選 Dock 圖示或選單欄 Hermes 圖示重新開啟。
- 選單欄、“視窗”選單和設定均可開啟或關閉桌面懸浮球。
- 懸浮球單擊提問、雙擊截圖、長按說話後鬆開傳送；右鍵、觸控板輔助點按或 Control＋點選開啟選單；點桌面其他位置或按 Esc 關閉選單。
- 圖片附件點選名稱預覽，單獨的 × 刪除。Command＋滾輪縮放，雙擊切換原始大小。
- 截圖前按系統提示允許螢幕錄製。許可權不足會停止本次截圖並提示；允許後重試，必要時退出並重開 Hermes。
- 錄音需要麥克風許可權。伺服器識別可直接使用；若 Mac 已安裝 Apple Command Line Tools，指令碼還會構建可選的系統識別元件。沒有該元件不影響伺服器識別和系統朗讀。
- 從應用選單選擇“退出 Hermes”或使用 Command＋Q 正常退出，會經過儲存草稿的流程。

## 簽名與驗證

生成指令碼會檢查 JDK 與程式位元組、Apple Silicon 架構、應用標識和版本、執行環境模組，並使用本機 ad-hoc 簽名及 `codesign` / `hdiutil` 驗證。它沒有進行 Apple Developer ID 簽名或公證，不作為已公證的公開發行包。

隨包 JDK 解壓後，指令碼僅清理經校驗的臨時構建目錄和生成應用上的下載隔離標記，不關閉系統 Gatekeeper、不改變系統全域性安全設定。

此輪編譯和迴歸測試運行於 Linux；Mac 選單欄、Dock、鑰匙串、螢幕/麥克風授權及最終 app/DMG 仍需在你的 Mac 上驗證。`validation/` 儲存本次自動化與打包檔案檢查記錄。

若生成失敗，日誌位於 `build/logs/`；請保留並提供最新的 `build-*.log`。生成成功後可刪除整個打包資料夾，安裝後的 Hermes 已帶獨立執行環境。
