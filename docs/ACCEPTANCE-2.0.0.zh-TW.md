# Hermes Desktop 2.0.0 驗收清單

本次以 Android 4.0.0 正式釋出原始碼為功能依據，在 Desktop 1.9.0（50b71c5d）上升級。使用原來的同一臺 Hermes 伺服器和 Profiles，首頁與業務記錄仍由伺服器 JSON／Markdown 儲存。

## 安裝與首次使用

- Windows x64：退出托盤裡的舊版 Hermes，再執行 `Hermes-Windows-x64-2.0.0-Setup.exe`。也可將便攜 ZIP 完整解壓到新目錄後執行 Hermes.exe。保留完整 app、runtime 目錄，無需另外安裝 Java。
- Mac M 系列（macOS 13 或更新）：退出舊版，解壓 `Hermes-macOS-arm64-2.0.0.app.zip`，將 **Hermes.app** 放到“應用程式”。2026-10-08 打包修訂 r2 的 ZIP 頂層只有這個應用。若舊包解壓後得到名為 `Hermes-macOS-arm64-2.0.0` 的異常應用，右鍵“顯示包內容”，如內有 `Hermes.app`，取出內層應用使用。系統首次攔截時，確認檔案來自本次驗收包後，在“隱私與安全性”中允許開啟。應用使用 ad-hoc 簽名，未作 Developer ID 公證。
- 沿用原閘道位址、賬號和 Profile。若舊版安裝目錄來自 MSI／jpackage，Windows 驗收安裝器可能安裝在新的應用目錄；驗證通過後再處理舊入口。不會自動刪除舊安裝或使用者資料。
- 先在首頁點“同步首頁”，讀取移動端已有內容；需要更新舊規則時再點“首頁設定 → 最佳化已有首頁和整理規則”。
- 本機語音包首次下載約 155 MB + 140 MB，建議預留至少 800 MB 空間。識別、朗讀可分別選擇本機／伺服器端／系統方式。

## 功能與驗收步驟

下列“待實機確認”是需要在你的真實電腦和伺服器上執行的步驟，不代表已經完成真機測試。

| 範圍 | 已實現 | 待實機確認的步驟與預期 |
|---|---|---|
| 兩種首頁 | 簡潔首頁／深入首頁，選擇持久儲存 | 切換、退出重開後保持；深入頁可按關注中、待收尾、提醒和領域篩選 |
| 手機／PC 共享 | 讀取同一工作區的首頁 JSON；舊路徑相容 | 手機上更新一張卡，PC 同步後看到相同事實和狀態；切換 Profile 不串資料 |
| 卡片展示 | 6 種佈局，來源、口徑、時間、最近完成 | 開啟包含進度／指標／日程的卡，檢查文字、來源和日期；縮小視窗／放大字級仍可滾動閱讀 |
| 卡片處理 | 20 類互動，輸入校驗、操作 ID、伺服器回執 | 選一項可撤銷的測試操作提交一次；雙擊不重複提交；只有伺服器回執核實後顯示完成 |
| 事項聊天 | 卡片背景帶入對話；結束後增量核對 | 從“聊聊這件事”進入，提供真實進展；完成後首頁更新；僅聊天不把事項自動標成業務完成 |
| 斷線恢復 | 保留操作和草稿，顯式“恢復原操作” | 提交後斷網再恢復：先同步核對，檢視原任務，不新開重複業務任務；重啟後仍能看到待核對狀態 |
| 首頁規則 | 最佳化規則、早晚任務與實際 Cron 核對 | 儲存 09:00／21:00 和時區後核對實際任務；重複儲存不增加重複 Cron；最佳化規則保留已有安排 |
| 舊檔案收納 | 顯式遷移、衝突時保留兩份 | 僅有舊路徑時出現收納入口；遷移後原業務 Markdown 和任務安排不變；已有新路徑無需遷移 |
| 後臺任務 | 首頁維護任務歸類，全部對話可檢視 | 首頁任務在任務中心可查，普通對話列表不被維護記錄佔滿；切到全部對話仍能找回記錄 |
| 連線與傳送 | 就緒握手、心跳、前臺／休眠感知、讀響應重試 | 新建空對話直接發第一句；斷網／喚醒後再發；不出現長期卡住；不確定的寫請求不自動重發 |
| 跨端授權 | 回答前同步待處理快照 | 手機上批准後 PC 舊請求消失；不能對過期或已變更的請求繼續提交舊答案 |
| 模型／思考強度 | lazy 後設資料相容，實際回讀優先 | 切換模型後發兩輪，重新進入仍正確；思考檔位僅展示伺服器端支援的選擇 |
| 名稱與草稿 | 保留 1–120 字元手工標題和錄音引擎 | 長標題、標點及連結重新載入不被截短；關閉重開後草稿／附件／待轉寫錄音可恢復 |
| 本機語音 | SenseVoice／Kokoro 下載、續傳、校驗、移除 | 下載中暫停再繼續；切到本機識別和朗讀，測試中文；拔掉網路仍可進行本機識別／朗讀（Agent 對話仍需伺服器連線） |
| 連續語音 | 完整句提前播放、預取、打斷、恢復聆聽 | 長回覆先朗讀完整句；點打斷後舊音訊立即停止；下一輪無上輪殘留句子；系統麥克風授權正常 |
| 連線幫助 | 內建離線指南、診斷摘要 | 未連線時可開啟指南；遠端伺服器不使用本機 localhost；診斷不輸出口令或聊天內容 |
| OSS | 按要求後置 | 本輪使用官方 GitHub 下載源，待驗收後再配置 OSS 位址、清單及更新渠道 |

## 已完成驗證

- JVM／MockWebServer／Compose 自動迴歸：346 項，339 通過，0 失敗，7 項因需要原生桌面環境而跳過。
- Android 同源首頁 writer 的 Python 測試：10 項全部通過。
- 9 個離屏介面：簡潔、深入、窄視窗大字級、紙間留白、流光玻璃、深色、首頁設定、會議分工互動、語音設定。
- 真實語音模型校驗、解包與 JNI 推理：Kokoro 生成 157,706 位元組 WAV，SenseVoice 準確識別為“你好，這是桌面版的本機語音測試。”；該驗證在 Linux CPU 上執行。
- Windows：對應平臺應用依賴、x64 Java 21 執行時與模組、NSIS 載荷逐檔案摘要；Mac：Apple Silicon 依賴、應用版本／入口、可執行許可權、重新簽名後的資源摘要。打包結果另附 SHA256SUMS 與構建清單。
