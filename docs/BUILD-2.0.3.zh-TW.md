# Hermes Desktop 2.0.3 構建說明

沿用 2.0.2 的 JDK 21、Gradle 8.13、Kotlin 2.3.20 和 Compose Desktop 1.10.1 依賴。應用 JAR 由當前原始碼重新編譯。

- 執行路徑解析、真實 HTTP 檔案讀取、歷史卡片恢復、工作空間恢復和桌面互動相關測試。
- 以 SHA-256 驗證 2.0.2 安裝包和依賴清單；依賴宣告未改變後複用各平臺依賴與原生執行時。
- 重新構建 Windows 原生啟動器與 NSIS 安裝器；安裝器使用同一份已校驗便攜包。
- Mac 替換應用 JAR 與版本資訊，重新進行 ad-hoc 簽名，校驗資源封裝、內碼表和歸檔執行許可權。

構建及包結構校驗不能代替 Windows / macOS 真機驗證。
