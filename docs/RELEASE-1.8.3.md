# Hermes Windows 1.8.3

本次修复六项交互与网关兼容问题。

1. 图片与截图附件可直接点击名称预览，支持缩放、拖动和原始大小查看。主聊天、工作台和浮窗使用同一组件，独立 × 按钮负责删除。预览读取草稿已有字节，不会提前上传或清空草稿；常见文本、PDF、表格、演示文稿也可查看，其他格式可保存到本机。
2. 思考文本保留网关发送的英文空格、换行和缩进，修复流式片段 trim 导致的单词粘连。已由旧版本保存为粘连文本的历史内容无法可靠自动补回空格。
3. 工作台最后一条最近会话不再显示下方横线。
4. 桌面悬浮球右键菜单、托盘菜单和快速提问窗使用柔和阴影及更宽的透明边距。
5. 截图覆盖层改为可获取焦点的工具窗口。Esc、右键、窗口关闭与截图结束均释放键盘监听并恢复浮窗。
6. 新旧网关确认协议兼容。新版服务端 JSON-RPC 的 clarify / approval 请求以原始 id 回应；旧版事件继续使用 clarify.respond / approval.respond。支持多问题、多选、自定义回答、锁定答案恢复、取消通知以及重连后的待确认事项恢复。主聊天和浮窗可直接打开确认面板，任务中心同步显示。遇到 session busy 会保留本次输入并尝试恢复服务器任务。

## 安装

在托盘菜单选择“退出 Hermes”，运行 Hermes-Windows-1.8.3-Setup.exe，使用原安装目录升级。无需卸载、无需另装 Java。账号配置、头像和草稿继续保存在原用户目录。

## 协议依据

实现对照 NousResearch/hermes-agent 的 tui_gateway/server.py 与 tui_gateway/server_requests.py（2026-09-15 检查）。请求恢复依赖网关实际提供 open_requests 或旧版 pending 字段。服务器本身未发出请求且不提供恢复字段时，客户端不能还原缺失选项；仍可停止任务。
