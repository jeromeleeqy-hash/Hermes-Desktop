## 安裝包檢查

Mac 使用使用者已確認能開啟的 2.0.0 應用作為原生執行時來源，全部應用 JAR 來自本次構建。打包指令碼逐項驗證架構、JAR、簽名內碼表、資源封印、許可權、ZIP CRC 與唯一 `Hermes.app/` 頂層目錄；任一失敗不產出交付包。

Windows 使用同一份 JVM 主程式和真正的 Windows x64 原生依賴；啟動器重新編譯。便攜包核對完整執行時的模組與摘要，安裝器校驗同一便攜包全部 JAR 和執行時檔案再編譯。

## 需要在你的電腦確認

- 退出舊版後替換／安裝 2.0.1，雙擊啟動；舊配置、對話與首頁正常恢復。
- 開啟實際的長命令待確認請求，滾動閱讀，核對允許、拒絕和稍後處理。
- 傳送普通訊息不再彈“已傳送”；傳送失敗仍有提示。
- 首頁設定可切換模式；真實卡片詳情標題、列表和完整正文正常。
- “設定 → 語音”下載並啟用 STT／TTS，試錄、試聽；允許系統麥克風許可權，核對實際裝置輸出。
- 斷開閘道後，本機試錄／試聽仍可用；恢復閘道後語音聊天正常。

本次沒有在 Windows 或 macOS 真機上執行新版本。Mac 2.0.0 已獲使用者啟動確認，不等同於 2.0.1 的真機驗收。真實閘道、原生許可權、休眠喚醒和物理音訊裝置不在此次 Linux 檢查結論內。
