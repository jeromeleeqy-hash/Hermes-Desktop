# Hermes Desktop 2.0.3

本次修復對話生成檔案無法開啟的問題。

- 相對路徑保留首級目錄，例如 `03_主题/活动/项目.md`；按來源對話的伺服器工作目錄讀取。
- 支援程式碼片段或引號中的中文、空格、括號檔名，保留 Windows 磁碟機代號與網路共享路徑。
- 避免對已解析路徑重複解碼，保留檔名中的加號、井號與百分號。
- 重新整理歷史檔案索引；舊檔案卡片讀取原訊息恢復完整路徑，遇到同名歧義時不猜選檔案。
- 不修改伺服器目錄、對話內容或已有檔案。

## 安裝

macOS Apple Silicon：退出舊版，解壓 app.zip，將 Hermes.app 替換到“應用程式”。
Windows x64：退出舊版後執行 Setup.exe，或完整解壓便攜 ZIP 使用。
請手動下載安裝；舊版自動更新器只識別 MSI / DMG。
