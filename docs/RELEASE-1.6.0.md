# Hermes Windows 1.6.0 · 桌面与文档体验

## 窗口与图标

- F1 清爽插画作为桌面应用图标，保留原始角色设计；应用图标与个人/助理头像独立。PNG 保留透明圆角，ICO 包含 16/20/24/32/40/48/64/96/128/256 像素。
- 拖动改为 AWT 屏幕坐标事件，避免移动窗口时局部坐标变化造成拖不动。完整双击只切换一次最大化，按钮区域不参与拖动。
- 最大化设置当前显示器工作区，并通过 WM_GETMINMAXINFO 设置原生边界，覆盖多显示器和任务栏位于不同边缘的情况。保留 Windows 11 DWM 圆角及 Windows 10 回退。

## 头像与交互

- 图片选择器绑定当前头像弹窗，支持直接点击头像选图；解码、裁剪、保存移到后台，增加处理中与错误反馈。支持 PNG/JPEG/GIF/BMP/WebP。
- 页面切换改为短位移、快速减速的淡入，减少突然闪空；悬停与按下反馈缩短起始延迟。仍遵循减少动效设置。

## Markdown

- 回车自动续写无序、有序、任务列表及引用；空列表回车退出；代码块与输入法组词不触发列表续写。
- 标题级别、删除线、格式再次点击取消、查找替换（可撤销）、文档内图片预览与相对链接/锚点。
- 后台解析、只绘制可见行号、光标跟随取消逐键滚动动画，减少长文档编辑抖动。保留源码、双栏、草稿、修改对比和保存前服务器冲突检查。

## 文件预览

- 图片：适应窗口、1:1、缩放、拖动平移、旋转与像素尺寸。
- PDF：单次打开文档、逐页绘制、跳页、缩略图、加密文件密码输入。
- Word（doc/docx）：段落、标题、强调、嵌入图片、表格阅读与缩放。
- Excel（xls/xlsx）：切换工作表、数字格式、已保存公式结果、合并单元格、每批 100 行/30 列与固定表头。
- PPT（ppt/pptx）：幻灯片绘制、缩略图、跳页和缩放。
- 网页（html/htm）：工作空间相对图片和 CSS 打包到内嵌浏览器，外部链接交给系统浏览器。

Office 预览不执行宏或外部公式，也不承诺复现全部 Office 字体、复杂排版、图表和动画。网页不运行脚本、不自动读取外部资源。

## 升级

新增 Apache POI 与更新后的 PDF 依赖。安装包自动更换应用依赖；便携更新包必须整体替换 app 目录。配置和草稿目录保持原有位置。

实现参考：[Windows 最大化边界](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-getminmaxinfo)、[Apache POI](https://poi.apache.org/)、[PDFBox](https://pdfbox.apache.org/download.html)、[jsoup](https://jsoup.org/download)。验证证据见 WINDOWS-VALIDATION.md。
