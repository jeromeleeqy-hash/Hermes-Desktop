# Hermes Desktop 1.8.4 — Agent 能力適配開發版

日期：2026-09-16。基於使用者提供的 1.8.3 完整原始碼及本對話懸浮球修訂。
狀態：已實現並打包原始碼；尚未通過完整 Kotlin/Compose 編譯、協議測試或 Windows/macOS 原生驗收。不是正式安裝包釋出。

## 本次變更

1. 聊天輸入區思考檔位入口：按伺服器端模型目錄明確宣告的 reasoning_efforts 展示；區分“能力未知”和“不支援”。僅修改當前對話；切換後回讀伺服器端結果。模型切換也檢查操作結果並回讀，重新開啟對話同步實際模型及思考檔位。
2. 新版互動請求：保留新舊審批/澄清；支援直接 request.cancel；未實現的請求型別顯示待處理卡，可開啟伺服器端明確提供的安全授權網址、檢查狀態，或由使用者明確拒絕。未公開協議的請求不會偽造成功答覆。請求缺少可確定的對話歸屬時返回協議錯誤，避免串到另一對話。
3. 連線恢復：單個在途健康檢查，HTTP 身份檢查與當前對話 WebSocket 檢查；失敗退避；全域性斷線/登入過期提示；重新登入保留工作區、草稿和附件。恢復時核對伺服器端狀態，不重發原提示詞。HTTP 寫操作關閉自動傳輸重試；提交結果不明時沿用已有取回結果機制。
4. 工具狀態：MCP 顯示可用、待連線、需授權、未配置、連線失敗、未知；可重新整理並開啟伺服器端返回的授權入口。無入口時說明需在伺服器端配置。診斷文本隱藏常見 token/password 欄位。沒有虛構自動安裝或 OAuth 啟動 API。
5. 圖片：明確識別 HEIC/HEIF/AVIF MIME；附件縮圖；相容預覽；優先使用現有解碼能力，必要時使用 macOS sips 或 Windows 系統圖片編解碼器。預覽對本機檔案處理，不上傳。使用者可顯式新增 PNG 首幀副本，原圖不變；超限不自動壓縮。原生轉換設超時、尺寸限制及臨時檔案清理。
6. 保留 1.8.3 懸浮球懸停防閃爍修訂，不包含雙 Agent 開發。

## 相容邊界

- 思考檔位依賴 /api/model/options 返回模型級 reasoning_efforts 後設資料，讀取模型物件或 provider.model_metadata 中的宣告。沒有宣告時只顯示當前值和重新整理入口，不猜檔位。
- 模型/思考更改使用現有 session.resume、session.status、config.set、slash.exec 介面。實際伺服器的欄位與響應格式仍需聯調。
- 審批、澄清可原地回答；其餘新請求為可見、可跳轉、可拒絕的相容處理，不代表所有新版互動都支援在用戶端原地完成。
- 登入恢復適用於本專案現有的使用者名稱/密碼閘道，不新增 Nous Portal 或 OpenRouter OAuth 登入協議。
- MCP 重新授權依賴伺服器端返回 authorization_url/auth_url；不自行拼接未知授權端點。
- HEIC/AVIF 並非所有 Windows 都可直接解碼，需要已安裝對應系統擴充套件；組織策略可能限制 PowerShell 指令碼。失敗時仍保留原圖和傳送/儲存入口。
- PNG 是首幀相容副本；不承諾儲存 HDR、所有 EXIF/ICC 資訊或多幀。對翡翠顏色的判斷應以原圖及實物為準。方向和色彩管理須在目標系統繼續核對。

- 已新增但未執行：4 項模型能力/授權網址單元測試、2 項 WebSocket 協議測試、1 項連線恢復工作區保留測試。

- 未完成：完整迴歸測試、Compose 介面檢查、真實 Hermes 閘道聯調、Windows/macOS 原生圖片解碼和懸浮球實測、原生安裝包構建。
- 包內舊版 docs/validation 報告屬於歷史版本，不能作為 1.8.4 的通過證明。

## 驗收重點

模型 A/B 支援不同檔位、未知能力、伺服器拒絕修改、切換對話時非同步返回；兩段對話同時出現請求、取消和重連恢復、重複點選提交；網路抖動、睡眠喚醒、登入過期、恢復不重複發任務；MCP 有/無授權入口；HEIC/HEIF/AVIF、旋轉及映象照片、Windows 缺少 codec、大圖/損壞圖、PNG 副本超限；三主題與字級放大、窄視窗；懸浮球單擊/雙擊/長按語音/拖動。
