# Hermes Windows 1.5.0 · 体验细化

- 窗口：双击改为识别完整点击，拖拽经过阈值才交给系统；Windows 11 使用 DWM 圆角，Windows 10 提供原生窗口形状回退，最大化恢复直角。记住普通窗口大小。
- 图标：清理应用图标的黑色不透明角，生成多尺寸 ICO；控件改用 Microsoft Fluent System Icons 的原版 20/24px Regular 与 Filled 资源，共 160 个。
- 菜单与弹窗：统一 10px／12px 圆角、紧凑行距、中性图标、分组间距、轻边框、悬停反馈和主按钮。工作空间、模型、文件、编辑、右键菜单采用同一套规则。
- 工作台：独立有限高度滚动容器和可见滚动条，小窗口和 150% 缩放可滚动到底部；增加输入框上方的滚轮回归。
- 主题：用真实界面缩略图替换抽象线框，并保持正确比例。
- Markdown：预览／编辑／双栏、语法着色、行号、搜索、目录、选区格式化、撤销重做、修改对比、阅读字号、任务清单、代码复制和草稿提示。窄窗口目录改用菜单。保留基础 Markdown 排版编辑入口。
- 中文编辑：输入法的一次组词作为一条撤销记录；编辑不经过 HTML 转换，原始文本保留。
- 动效：页面和提示淡入、悬停与按下渐变、开关滑动、折叠展开过渡；遵循减少动效设置。
- 分发：新增 NSIS 安装包和原生启动器，支持当前用户安装、开始菜单、可选桌面快捷方式和卸载保留用户数据。

这是客户端更新，继续使用现有 Hermes 网关与账户。安装包与便携版来自同一份已校验的 Windows 应用和运行环境。

验证记录及尚未在真机验证的项目见 WINDOWS-VALIDATION.md。
