# Hermes Desktop 2.0.4

- 普通接口的连接检查不再调用会话状态 RPC，也不会因该 RPC 超时而主动切断实时通道。
- 分别处理普通接口可达性和实时通道恢复；两次连续连接探测失败后才显示服务器无法访问。实时通道恢复期间，继续读取消息和会话列表。
- 当前会话定期核对服务器任务，手机发起的任务在 PC 显示处理状态，服务器明确结束后清除状态。已知会话的服务器事件触发刷新，轮询作为兜底。
- 当前会话的未读标记与正文读取协调；只有成功读取正文才推进已读位置。保留草稿、附件和已经加载的历史。
- 聊天正文隐藏完整且长度校验通过的 Hermes App 内部上下文。列表摘要同时处理服务器截断的预览；模型上下文与存储原文不改写，代码示例和不完整正文保留。
- 恢复连接与同步不会重新提交问题，也不会自动发送此前保留的排队消息。
