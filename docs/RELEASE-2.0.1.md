# Hermes Desktop 2.0.1

本次处理 2.0.0 实际使用中的五项反馈。

- 待确认操作改为短标题、独立的命令阅读区和固定操作区。命令使用等宽字体，可选中、复制、滚动；长内容不会把允许／拒绝按钮挤出窗口。聊天、任务中心、小窗使用同一组件。
- 普通消息被服务器接收后，只更新对话内状态，不再弹出“已发送”。发送失败、排队和需要用户处理的提示仍保留。
- 首页模式切换收进“首页设置”。同步、更新进展与设置放到事项区域，简洁首页位于输入框下方，不再占据页面最顶端。
- 首页详情支持 Markdown 标题、段落、强调、列表、代码与链接。兼容旧卡片中的字面换行和【标题】，正文保留完整；仅调整展示，不修改卡片内容、指纹或交互数据。
- 语音设置顶部提供本地 STT／TTS 模型卡片，一键下载并启用；支持进度、暂停续传、SHA-256 校验、导入已下载的模型包、试录和试听。

## 使用本地语音

进入“设置 → 语音”，分别在“本地语音识别 · STT”和“本地语音朗读 · TTS”点击“下载并启用”。SenseVoice 识别包约 155 MiB，Kokoro 朗读包约 140 MiB。安装完成后即可试录或试听；两个引擎可以独立选择。

如果应用内下载不便，点击“手动下载”，保留下载到的 `.tar.bz2` 文件，再用“导入模型包”选择它。导入同样核对固定的文件大小与摘要，原始文件不会被删除。

模型安装后，本地试录和试听不依赖网关。语音对话的文字回复仍需要 Hermes 网关。本地模型发生错误或被移除时会说明原因，不会自动改成服务器识别或上传录音。下载完成时如果正在使用语音，可在结束后启用，避免中途切换。

## 更新安装

Mac Apple Silicon：退出正在运行的 Hermes，解压 `.app.zip`，把其中唯一的 `Hermes.app` 替换到“应用程序”。归档内保留可执行权限和应用结构，不再生成多余的外层 `.app`。

Windows x64：使用 Setup.exe，或完整解压便携包。安装包与便携包使用相同应用代码和内置运行时。
