# Beta 3a 寬屏與主題複核

1. 解壓完整原始碼到 `Hermes-macOS-beta-3a` 新目錄，執行 `Run-Hermes.command`；幫助頁版本為 `1.0.0-beta.3a`。現有 JDK 21 可繼續使用。
2. 將視窗拉寬，收起檔案欄，檢查首頁歡迎區與人物、對話和產物分割槽；內容不應隨視窗無限拉開，摘要不應露出內部提示標記。
3. 任務中心分別檢視無待處理、一個完成任務和多個執行任務。三列應對齊、顯示數量；審批和澄清可點選檢視詳情，操作仍作用於原任務。
4. 切換三套皮膚，特別檢查玻璃主題的左側欄和主題卡片。名稱、說明和縮圖應完整，滑鼠點選不應產生厚重灰框。
5. 在較小視窗滾動設定頁至“儲存資料”，再切換其他設定項；檢查 Retina 下圖示、卡片邊緣和文字可讀性。
6. 從設定或首頁點選檔案圖示，確認返回當前聊天並展開右側檔案欄；未傳送文字、文件編輯與滾動操作保持正常。

以下保留之前版本的完整功能複測路徑。

# Beta 3 介面複測

1. 關閉舊版，解壓完整原始碼到 `Hermes-macOS-beta-3` 新目錄，雙擊 `Run-Hermes.command`。設定的幫助頁應顯示 `1.0.0-beta.3`。不要只複製一個指令碼到舊目錄。
2. 檢查左側為圖示欄，底部只有一個設定入口。懸停等待名稱提示，Tab 切換可見焦點。
3. 在聊天中輸入未傳送內容，切換右側目錄、搜尋檔名、收起／展開檔案欄，確認對話和輸入仍保留；重啟後確認側欄狀態保留。
4. 開啟文件編輯後切換另一個檔案或返回聊天，再次開啟原文件，確認最新修改保留；另檢查本機草稿、儲存、下載和來源對話。
5. 切換三套皮膚，分別檢查面板邊界、訊息署名、圓角、紙張紋理與半透明層次；淺色／深色都應清晰可讀。
6. 在 1160×760 與較大視窗檢查輸入區、檔案欄、執行中停止／排隊／追加按鈕。滾到歷史訊息時，“跳到底部”應在輸入區上方，不蓋住訊息；點選回到最新回覆。
7. 滑鼠經過篩選、複製／朗讀、圖示和選單：不再出現通用灰色矩形，保留有用途的文字或輪廓反饋。
8. 開啟命令、語音、頭像、定時任務、未儲存文件提示與服務商彈窗，確認隨當前主題顯示、內容可滾動、Esc 可關閉。

9. 檢查新增附件／選擇頭像和另存文件使用 macOS 檔案視窗；取消不寫入，覆蓋現有檔案遵循系統確認。

# Beta 2 登入複測

1. 解壓完整 Beta 2 到新目錄，用 `Run-Hermes.command` 執行，或用 `Package-macOS.command` 打包。登入頁底部應顯示 `1.0.0-beta.2`。
2. 填寫與網頁登入完全相同的閘道位址（含埠）、使用者名稱和密碼。點選“顯示”核對輸入，提交時會自動恢復遮擋。
3. 連線成功後測試對話讀取；退出應用再開啟，檢查已有登入狀態恢復。
4. 若仍失敗，關閉提示框，點選“複製登入診斷”並提供診斷文字。無需提供密碼、Cookie 或令牌。請同時說明瀏覽器是重新輸入賬密登入成功，還是直接沿用已登入的頁面。
5. 新入口不執行測試；需要完整迴歸與打包時使用 `Build-macOS.command`。

# Mac 功能驗收

基礎框架已經由使用者執行。本表用於驗證本輪新增能力。建議先使用普通測試對話、測試文件和臨時定時任務。

## 對話與恢復

1. 執行 Run-Hermes.command，確認舊登入／稱呼可以讀取；切換 Profile，檢查專案與對話相互隔離。
2. 同時執行兩個對話，檢查回復、工具進度、追加要求和停止都路由到自己的對話。
3. 在草稿中放入文字、圖片、文本附件，關閉應用再開啟，應完整恢復。
4. 任務執行時排隊兩條訊息；正常完成應逐條傳送。執行中關閉應用再開啟，應先恢復結果，佇列等點選“繼續傳送佇列”才繼續。
5. 任務執行時斷網再恢復，確認沒有重複提交。兩次傳送相同問題時不能把舊答案判成新任務完成。
6. 試用對話搜尋、命中定位、日期篩選、歸檔／恢復、提示詞片段和命令。會審依賴實際 MoA／委派能力。

## 檔案與任務

1. 編輯 Markdown 的最後幾個字，立即按 ⌘ S，檢查中文輸入法組合輸入和焦點切換；再測試原始碼模式和複雜 Markdown。
2. 開啟兩份文件，分別編輯並切換標籤；關閉應用後從“檔案 → 本機草稿”繼續，兩份內容應分別保留。
3. 在另一端修改同一檔案，再從桌面儲存，應該提示遠端內容變化而不是直接覆蓋。
4. 預覽圖片、多頁 PDF、靜態 HTML；測試下載、複製路徑、來源跳轉和新增到對話。
5. 測試審批和單選／多選澄清。重複點選不能重複回答；重啟後仍可檢視待處理記錄。
6. 臨時建立定時任務，核對伺服器時區，驗證詳情、編輯、暫停／恢復、立即執行和刪除。

## 語音與系統能力

1. 首次錄音允許麥克風訪問；單次錄音結束後確認文字回填。
2. 進入連續語音，在安靜與有風扇聲的環境各說一句，確認自動判斷停頓；測試中途打斷、關閉視窗、回覆朗讀後重新聆聽。
3. 錄音識別過程中斷網，之後在語音設定的錄音記錄中重試。已經回填的同一錄音不應再次自動重複追加。
4. 錄音後切換對話或 Profile，結果應保留在原對話，不得進入新聊天。
5. 朗讀長回覆和中文內容，檢查分段、語速和系統回退。系統識別只在已編譯 HermesSpeech 時可選。
6. 將應用放到後臺等待回覆和審批通知；檢查通知開關、聲音和 Dock 未讀標記。
7. 更換兩種頭像、切換主題和中英文，重啟檢查偏好。拖動視窗調整尺寸，檢查下次恢復。

## 打包與真實閘道

在 Mac 上執行 Build-macOS.command，生成 DMG，拖入 Applications 再測試登入、鑰匙串、麥克風和系統識別。開發 Java 程序與安裝後的應用可能需要分別授權。

模型、記憶、語音、Skill／工具集／MCP 設定請與手機版比對。Agent 更新會改動伺服器，僅在確認需要更新、沒有執行任務時通過介面確認執行。

報告問題時提供 Mac 晶片、macOS 版本、啟動方式、復現步驟和終端錯誤。不要貼密碼、Cookie 或 API Key。應用不會自動上傳診斷日誌。
