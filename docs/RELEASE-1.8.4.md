# Hermes Desktop 1.8.4 — Agent 能力适配开发版

日期：2026-09-16。基于用户提供的 1.8.3 完整源码及本对话悬浮球修订。
状态：已实现并打包源码；尚未通过完整 Kotlin/Compose 编译、协议测试或 Windows/macOS 原生验收。不是正式安装包发布。

## 本次变更

1. 聊天输入区思考档位入口：按服务端模型目录明确声明的 reasoning_efforts 展示；区分“能力未知”和“不支持”。仅修改当前会话；切换后回读服务端结果。模型切换也检查操作结果并回读，重新打开对话同步实际模型及思考档位。
2. 新版交互请求：保留新旧审批/澄清；支持直接 request.cancel；未实现的请求类型显示待处理卡，可打开服务端明确提供的安全授权网址、检查状态，或由用户明确拒绝。未公开协议的请求不会伪造成功答复。请求缺少可确定的会话归属时返回协议错误，避免串到另一对话。
3. 连接恢复：单个在途健康检查，HTTP 身份检查与当前会话 WebSocket 检查；失败退避；全局断线/登录过期提示；重新登录保留工作区、草稿和附件。恢复时核对服务端状态，不重发原提示词。HTTP 写操作关闭自动传输重试；提交结果不明时沿用已有取回结果机制。
4. 工具状态：MCP 显示可用、待连接、需授权、未配置、连接失败、未知；可刷新并打开服务端返回的授权入口。无入口时说明需在服务端配置。诊断文本隐藏常见 token/password 字段。没有虚构自动安装或 OAuth 启动 API。
5. 图片：明确识别 HEIC/HEIF/AVIF MIME；附件缩略图；兼容预览；优先使用现有解码能力，必要时使用 macOS sips 或 Windows 系统图片编解码器。预览对本机文件处理，不上传。用户可显式添加 PNG 首帧副本，原图不变；超限不自动压缩。原生转换设超时、尺寸限制及临时文件清理。
6. 保留 1.8.3 悬浮球悬停防闪烁修订，不包含双 Agent 开发。

## 兼容边界

- 思考档位依赖 /api/model/options 返回模型级 reasoning_efforts 元数据，读取模型对象或 provider.model_metadata 中的声明。没有声明时只显示当前值和刷新入口，不猜档位。
- 模型/思考更改使用现有 session.resume、session.status、config.set、slash.exec 接口。实际服务器的字段与响应格式仍需联调。
- 审批、澄清可原地回答；其余新请求为可见、可跳转、可拒绝的兼容处理，不代表所有新版交互都支持在客户端原地完成。
- 登录恢复适用于本项目现有的用户名/密码网关，不新增 Nous Portal 或 OpenRouter OAuth 登录协议。
- MCP 重新授权依赖服务端返回 authorization_url/auth_url；不自行拼接未知授权端点。
- HEIC/AVIF 并非所有 Windows 都可直接解码，需要已安装对应系统扩展；组织策略可能限制 PowerShell 脚本。失败时仍保留原图和发送/保存入口。
- PNG 是首帧兼容副本；不承诺保存 HDR、所有 EXIF/ICC 信息或多帧。对翡翠颜色的判断应以原图及实物为准。方向和色彩管理须在目标系统继续核对。

## 验收重点

模型 A/B 支持不同档位、未知能力、服务器拒绝修改、切换会话时异步返回；两段会话同时出现请求、取消和重连恢复、重复点击提交；网络抖动、睡眠唤醒、登录过期、恢复不重复发任务；MCP 有/无授权入口；HEIC/HEIF/AVIF、旋转及镜像照片、Windows 缺少 codec、大图/损坏图、PNG 副本超限；三主题与字号放大、窄窗口；悬浮球单击/双击/长按语音/拖动。
