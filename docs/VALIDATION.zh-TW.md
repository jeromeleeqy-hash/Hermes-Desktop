## Beta 3 桌面介面

主程式在 Linux + JDK 21 編譯通過；Gradle `test` 的 86 項自動測試全部通過，0 失敗、0 錯誤、0 跳過。保留登入、閘道併發、檔案、錄音、草稿恢復等已有迴歸。

新增 4 項狀態迴歸驗證：

- 瀏覽目錄、切換專案與收起檔案欄，不改變當前聊天、未傳送草稿和未儲存文件。
- 開啟另一份檔案時等待富文本編輯器讀取最新輸入，並保留上一份文件的修改。
- 從文件返回聊天時等待富文本讀取完成，避免切換頁面丟失最新輸入。
- 檔案欄顯示偏好經真實加密配置儲存後可以在新控制器中恢復。

實際 Compose 程式碼渲染 16 種介面狀態，並另外儲存篩選懸停截圖，共 17 張，位於 `docs/previews/beta3/`：三種聊天皮膚、收起檔案欄、設定、1160×760 執行中聊天、歷史訊息跳轉、三種主題彈窗、英文深色、首頁、文件、任務、對話列表及助理側欄。截圖使用演示資料，不包含 macOS 標題欄。彈窗截圖使用與真實彈窗同一個內容元件。

渲染時注入真實指標事件，檢查檔案欄收起／展開、時間篩選懸停以及跳到底部。篩選按鈕懸停前後的截圖逐位元組一致，沒有額外繪製矩形；跳轉按鈕的底邊位於輸入內容頂部之外，點選後到達末尾並隱藏按鈕。截圖檢查中發現並修復了深色模式預設文字顏色問題。

Mac 啟動／打包入口沿用已修復版本；原始碼包檢查 CRC、指令碼執行許可權、必要檔案和主程式 SHA-256 清單。檔案選擇／另存採用 AWT 對應的 macOS 原生視窗，取消及覆蓋確認仍需在 Mac 上覆核。當前 Linux 環境沒有實際生成或執行 macOS DMG，也未連線使用者閘道執行本版 UI 的完整端到端測試。

使用者已確認前一版能在 Mac 編譯、連線閘道，基礎功能可用；本版真機複核步驟見 [MAC-ACCEPTANCE.md](MAC-ACCEPTANCE.zh-TW.md)。以下保留早期版本的驗證歷史，其中“待使用者驗證”描述的是當時狀態。

## Beta 2 登入迴歸

本次在 Linux + JDK 21 上重新編譯主程式並執行全部 82 項測試，0 失敗、0 錯誤、0 跳過。新增 `GatewayLoginTest` 的 9 項檢查通過真實本機 HTTP 服務與實際加密 Cookie 儲存驗證：

- 密碼中的前後空格、引號、反斜槓、加號、中文、重音字元和 Emoji 按原文提交；請求欄位及 JSON 編碼與閘道介面一致。
- 登入返回的 Cookie 用於 `/api/auth/me`，重建用戶端後可恢復已有登入狀態；支援閘道路徑字首。
- 空賬號／密碼在網路請求之前被拒絕。
- 提交密碼時被拒絕、提交後對話驗證失敗、恢復舊對話失敗有不同的失敗階段。
- 401 認證拒絕與 429 限流不會重複提交密碼。
- 登入方式介面返回非 JSON 時不傳送密碼。
- 診斷不包含原始伺服器響應，即便錯誤響應回顯敏感內容也不會進入彈窗或診斷；本機儲存錯誤有獨立分類。

實際 Compose 程式碼另渲染了 1440×900 和 1160×760 兩種登入頁，檢查了新增“顯示”按鈕、停用的空密碼提交按鈕與用戶端版本。截圖見 `docs/previews/login-beta2.png` 和 `login-narrow-beta2.png`。已有八張功能頁面截圖來自 Beta 1，此次未重渲染。

當前仍沒有使用者閘道的現場 HTTP 結果，未復現其第一次 `Invalid credentials`，也未驗證 Mac 上的密碼輸入法與實際登入。使用者已確認上一版在 Mac 上編譯成功；本次登入更新仍需在該裝置運行復測。測試通過不等同於已解決真實閘道認證。

## Beta 1 打包入口補丁驗證

補丁 2：使用實際交付的 Preview 1 壓縮包檔案結構復現了上一個指令碼的錯誤提示，再用修訂指令碼驗證了以下情況：

- 舊 Preview 1 缺少整套原生語音輔助檔案時，通過工程檢查，顯示 `1.0.0-preview.1`，並提示指令碼不會升級原始碼。
- 完整 Beta 1 通過工程檢查，顯示 `1.0.0-beta.1`。
- Beta 1 僅缺少 `prepare-native.sh` 時準確列出該檔案並停止；基礎檔案同時缺少多項時一次列出全部。
- 補丁未放入工程時給出實際缺失列表和放置說明；含中文、空格的工程路徑識別正確。
- `bash -n` 通過，57 個主程式原始碼仍匹配原有 SHA-256 清單。

這些檢查在 Linux 上執行；完整工程的指令碼執行到 macOS 平臺檢查後按預期停止，沒有執行原生工具或生成 DMG。此前測試庫下載問題仍通過獨立打包入口避開，沒有修改網路或 TLS 配置。

2026-09-10 新增 `Package-macOS.command` 後，在 Linux + JDK 21 下執行以下檢查：

- `bash -n` 通過；指令碼可執行許可權與非 macOS 平臺提示檢查通過。
- Gradle `packageDmg --dry-run --offline` 成功，任務圖包含主程式編譯、JAR、資源和打包任務，不含 `compileTestKotlin` 或 `test`。這是任務圖檢查，未實際生成 DMG。
- `dependencyInsight --dependency org.mockito --configuration runtimeClasspath --offline` 確認主程式執行依賴中沒有 Mockito。
- 57 個主程式原始碼檔案逐一匹配原有 SHA-256 清單；原打包指令碼、依賴配置、JDK 檢測和原生元件準備指令碼與此前交付的 Beta 1 完全相同。

此次只新增打包入口及說明，沒有重跑上述 73 項應用測試。新增入口不執行測試；原 `Build-macOS.command` 仍先執行測試，失敗時停止。使用者 Mac 上的 TLS 下載錯誤與 DMG 生成仍需在其環境中驗證。
