# Hermes Desktop 2.0.4 驗收記錄

針對連線恢復、跨端同步、訊息呈現、未讀、請求路由及本機恢復的 74 項 JVM 測試通過，0 失敗。

模擬閘道驗證了即時連線關閉而 HTTP 正常時仍收到手機訊息、重新連線不重複提交、手機任務出現和結束、事件觸發更新、正文讀取失敗不推進已讀、草稿附件及已載入歷史保留，以及本機流式回覆不會被舊讀取覆蓋。內部上下文測試包含中文、Emoji、多段、錯長、缺失尾標和程式碼示例。

結果見 validation/desktop-2.0.4-junit 與 validation/desktop-2.0.4-validation.json。構建環境初次未指定無介面模式時，桌面測試因缺少本機 X11 庫未能執行；按專案的無介面測試配置重新執行通過。

包組裝過程校驗依賴與應用 JAR 雜湊、Mac 資源簽名和歸檔許可權、Windows 執行時及安裝器載荷。未在 Windows / macOS 真機執行，也未訪問使用者的實際閘道；實際網路斷連原因和閘道跨用戶端廣播能力仍需現場驗證。
