# Hermes Windows 1.8.1

发布日期：2026-09-14

## 界面修正版

- 左侧导航顶部重新布局：Hermes 标识与品牌名称独立呈现，个人头像、昵称和工作空间组成统一的账户区域。点击品牌返回工作台，点击个人资料进入外观与账户，工作空间仍可直接切换。
- 托盘和悬浮球右键菜单统一采用软件内的字体、圆角、边框、阴影、图标及悬停动画，跟随主题、深浅模式和文字大小，解决原生菜单中文字显示为方框的问题。
- 菜单支持键盘选择、Enter 操作和 Esc 收起；点击外部收起，多个菜单互斥。靠近屏幕边缘时自动调整位置，避开任务栏。
- 托盘菜单提供打开 Hermes、悬浮球开关、设置及完整退出；悬浮球菜单保留提问、框选截图、连续语音、打开主窗口及关闭悬浮球。
- 修正版继续使用 1.8.1 版本号，提供完整安装程序及源码；覆盖安装到原目录即可。

## 悬浮球按住说话

- 按住鼠标左键约 0.55 秒进入录音，录音期间显示“松开鼠标，识别后发送”。说话中的短暂停顿不会提前提交。
- 松开鼠标即停止录音，识别完成后自动发送到悬浮球当前选择的会话。此行为不受普通录音的“自动发送”偏好影响。
- 松开位置可以在悬浮球以外；弹出提问小窗时不会抢走按住手势的焦点。
- 同一次松开只结束一次录音；识别期间再次长按不会中断或重复提交上一段语音。
- 回复完成后等待下一次按住；按住模式不会自动开启下一轮麦克风。持续语音仍可通过语音按钮或右键菜单进入。
- 目标会话正在执行任务时，新的语音问题加入该会话队列；模型切换或附件读取未完成时，识别文字保留在草稿中。
- 会话尚未准备好就松开时，取消延迟录音并提示重新按住。关闭小窗、切换会话、关闭悬浮球不会将取消的录音自动发出；可用录音保留在原会话的语音记录中。
- 未识别到内容时不发送空消息；识别失败的录音可重试。

单次录音仍沿用最多 60 秒的保护上限；达到上限后停止录音，仍等松开鼠标才发送。

## 完整安装与源码

- 应用、启动器与安装程序统一为 1.8.1；沿用已确认的 C1 图标。
- 合并 1.8.0 启动修复：运行环境补齐桌面互操作模块，启动前检查实际模块，并将两路 JVM 输出写入同一完整日志。
- 提供完整 Setup 安装包及完整源码包。安装包内含 Windows x64 运行环境，不需要另装 Java。
- 源码包含构建、测试、资源及安装打包脚本；可直接从已链接的 Windows 运行环境打包，不依赖旧版便携包。

## 升级

在 Windows 右下角系统托盘中右键 Hermes，选择“退出 Hermes”，再运行 `Hermes-Windows-1.8.1-Setup.exe`，沿用原安装位置。用户配置、头像、会话缓存和草稿继续使用原数据目录，无需卸载。

验证证据与环境限制见 [WINDOWS-VALIDATION.md](WINDOWS-VALIDATION.md)。
