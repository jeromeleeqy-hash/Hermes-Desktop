# 与 Android 3.6.5 的功能对齐

版本：1.0.0-beta.3。用户已确认前版可以编译、连接网关并使用基础功能。本版优化桌面布局，新增交互仍需按真机步骤复核。

| 功能 | 本版实现 | 具体边界 |
| --- | --- | --- |
| 登录、Profile、项目 | 复用原登录与项目协议；各 Profile 独立客户端；记住项目选择 | Keychain、服务器权限需真机确认 |
| 会话管理 | 新建、固定日常助理、重命名、AI 标题、置顶、归档、恢复、项目移动、删除 | 移动端触摸操作映射为桌面菜单 |
| 历史与搜索 | 历史分页、项目／时间筛选、内容搜索、命中消息定位 | 搜索最近最多 100 个会话，每个最近 200 条消息 |
| 聊天渲染 | Markdown、代码、表格、图片、推理展开、复制、引用来源 | 流式期间先显示文字，结束后排版 |
| 命令与提示词 | 分类／搜索服务器命令；提示词增删改、排序、恢复默认、填入草稿 | 填入后由用户决定发送 |
| 附件 | 本机图片／文本、拖入、服务器文件路径、随草稿持久化 | 沿用手机版的数量与大小限制 |
| 运行与队列 | 多会话隔离、工具进度、追加要求、排队、停止、完成记录 | 恢复后的队列需要显式继续 |
| 断线／重启恢复 | 提交前持久化运行标识、原问题与附件；取回服务器后续回复；不自动重发 | 服务器消息不足以确认结果时继续保留恢复状态 |
| 审批／澄清 | 服务端选项、单选／多选／自由输入、响应中状态、持久化、来源跳转 | 过期记录可手动移出；不会替用户作答 |
| 专家会审 | 快速 MoA、深度真实子 Agent、真实专家返回展开 | 依赖服务器配置和委派工具；提示词约束工具不可用时明确降级 |
| 定时任务 | 列表、详情、新建／编辑、暂停／恢复、立即运行、删除 | Cron 表达式与时区由服务端解释 |
| 文件浏览 | 可收起右侧栏、目录、路径、文件名搜索、最近产物、来源定位 | 搜索范围为当前目录，不宣称全服务器全文搜索 |
| 文档编辑 | 多标签、预览／富文本／源码、未保存草稿、重启恢复、保存／下载 | 复杂 Markdown 默认源码；服务器没有原子条件写入 |
| 图片／PDF／HTML | 图片缩放、PDF 分页渲染与错误提示、静态 HTML 预览 | HTML 禁止脚本与远程资源，不作为通用浏览器 |
| MEMORY／SOUL | 当前 Profile 文件读取、预览与编辑 | 保持原服务端内容与路径规则 |
| 单次语音 | WAV 录音、服务器／系统识别、中文简繁转换、回填／自动发送、失败录音重试 | 录音绑定开始时的会话；Mac 硬件及授权待测 |
| 连续语音 | 自动判断停顿、噪声适应、60 秒录音上限、分段朗读、语速、打断、继续聆听 | 原生 Speech 辅助程序需 Apple Command Line Tools 编译；无组件时使用服务器 |
| 模型与对话设置 | 默认、会话、辅助、备用模型、推理、上下文、MoA、自定义服务商、人格和时区 | 模型可用性取决于服务器实际配置 |
| 记忆与审批设置 | 记忆／档案开关及上限、压缩阈值与目标、保护消息数、审批模式／超时 | 数值范围沿用服务端约束 |
| Skills／工具／MCP | 读取、Skill 内容、启停 | 服务端未提供的管理接口不在客户端虚构 |
| Agent 更新 | 检查、提交官方更新接口、进度与日志、重新连接 | 更新前在界面确认并结束运行任务；未调用用户真实服务器 |
| 个性化 | 独立头像裁剪、昵称、助理名、简介、人物动画、减少动态 | 桌面采用现有布局，三种主题使用不同色调与侧栏渐变，未使用 Apple 原生 Liquid Glass API |
| 语言 | 中英文界面切换、系统语言选择、协议文案切换 | 服务器返回的内容、用户文本和部分错误详情保留原文 |
| 桌面能力 | 菜单、快捷键、窗口尺寸记忆、文件拖入、剪贴板、通知、Dock 标记 | 麦克风、系统识别、通知与打包身份需在 Mac 确認 |

Android 的系统分享入口、震动、返回手势等不照搬；桌面用拖入文件、系统通知、菜单和键盘完成相应操作。完整业务流程已经实现，正式发布仍以真实网关和 Mac 验收结果为准。
