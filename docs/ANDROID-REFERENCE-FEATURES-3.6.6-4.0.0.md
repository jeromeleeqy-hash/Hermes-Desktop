# 3.6.6 → 4.0.0 新功能

当前功能的使用方法；历史版本逐项变化请看更新日志。

### 首次使用：连接自己的 9119 网关

1. 首次打开先阅读三步说明，再设置本机显示的昵称和头像。已有用户升级保留设置，不会被要求重新配置。
2. 在运行 Hermes Agent 的服务器或电脑上启用远程网关，通常监听 9119，并设置网关用户名和密码。手机需能访问该服务器。
3. 连接页填写 http://服务器IP:9119；如果已有 HTTPS 反向代理，填写完整 HTTPS 地址。不要填 localhost，也不要自行追加 /api 或 /v1。
4. 验证并连接后即可聊天。连接页或“我的 → 使用说明 → 30 秒上手与 9119 连接”可以重看说明。

4.0.0 新增。App 是移动终端，不会在手机上安装完整 Hermes Agent；局域网或可信 VPN 可用 HTTP，公网建议 HTTPS。

### 两种首页：先简洁，再按需深入

1. 新用户默认进入简洁首页。用“跟我说”聊天，在“回看”“任务”“文件”继续日常操作，不需要配置整理功能。
2. 想集中查看待办和近期进展时，打开首页齿轮，切换到“深度助理”。
3. 首页设置用模式卡片和状态面板说明当前配置；按提示完成首次整理。已有首页内容时，首次整理会显示已完成。
4. 可以随时切回简洁首页。已配置的服务器早晚任务不会因此暂停，需要时到“任务”管理。

3.8.4–3.9.3 完善。首页人物现为一段约 15 秒的本机循环动画；开启“减少动态效果”后显示静态形象。

### 处理事项：自然聊天，完成后自动核对

1. 点开首页事项，先看背景和详情；可以“聊聊这件事”，也可以提交卡片提供的快捷回应。
2. 在对话中直接说明最新进展。卡片相关对话结束后，App 会在后台请求核对，不必每次回首页手动刷新。
3. 收到建议或讨论方案不会直接把卡片标为完成。状态以服务器保存的实际结果为准；普通聊天的进展也可用首页刷新合并。
4. 处理需要授权、澄清或结果核对时，进入“任务”或“查看处理”继续，不要重复发送同一项操作。

3.7.x–3.8.7 新增并完善。首页数据和任务处理分开核对，收到任务不等于已经完成。

### 看清变化：新增、完成与最近核对

1. 首页成功同步后，会提示新增事项和已完成事项；最近完成的内容留有记录，便于确认结果。
2. 提交简短信息后，先看到送达或处理中的反馈，随后再显示服务器核对出的实际变化。
3. 区分“内容更新时间”和“最近核对”：定时任务正常运行但没有新内容时，内容时间可能不变。
4. 卡片按结论、背景和指标组织内容。统计数字如有范围、时间或口径说明，可在详情中一起查看。

3.8.9–3.9.2 新增。时间和变化提示基于同步结果，不会为了显示“有更新”而改写服务器数据。

### 一次配置：早晚整理与文件收纳

1. 在首页齿轮里查看首次整理、早晚整理和文件收纳的状态，只操作尚未完成或需要调整的项目。
2. 早晚整理设置时间和时区后，由服务器按计划执行；以后只有改变安排时才需要重新配置。
3. 首页 JSON、锁文件和快照统一放在工作区 .hermes-app/today/。旧版用户按“文件收纳”迁移一次，业务文件仍留在原处。
4. 如需应用新的卡片内容规范，打开维护工具中的“更新整理规则”；保留已有整理时间与启用状态。

3.7.x–3.9.3 完善。安装 App 更新不会自行修改服务器 Cron；执行记录与故障请在“任务”中核对。

### 任务与授权：集中查看，减少会话干扰

1. 自动整理、卡片处理等后台工作集中在“任务”查看，手机“回看”主要保留你主动开始的对话。
2. 需要批准或补充信息时打开对应任务；同一项授权在其他端处理后，可重新核对服务器状态。
3. 遇到执行中断或结果待核对，先查看已有进展，再选择继续未完成部分或核对结果。

3.8.x 完善。临时任务只在手机会话列表中隐藏，服务器和 PC 记录仍保留；当前不会自动销毁服务端对话。

### 对话更顺手：复制、朗读、重命名与恢复

1. 回答完成后可复制完整正文或点“朗读”。语音设置可分别选择识别语言和朗读方式。
2. 在“回看”长按对话，选择“重命名”，手动输入名称并保存，不再为改名调用 AI。
3. 将手机文字、链接或文件分享给 Hermes，确认后发送；取消或处理过的分享不会因重新打开 App 重复弹出。
4. 网络中断后 App 会尝试恢复会话状态。结果未确认时先查看已有回复，避免重复发送；连接页可查看诊断。

3.6.6 起完善语言、复制与朗读；3.8.7 加入手动改名，3.8.9 修复连续提问恢复及旧分享重复弹窗。

### 端侧语音：识别与朗读可以分别选择

1. 打开“我的 → 设置 → 语音”，在“手机端侧语音”按需下载 SenseVoice 识别包或 Kokoro 朗读包。页面显示本版的下载来源。
2. 下载支持暂停续传和校验；下载完成后，手动将“识别方式”或“朗读方式”切换为“手机端侧模型”。
3. 两项可以独立选择，例如手机本地识别搭配 Hermes 服务端朗读。也可以继续使用系统语音或原来的服务端配置。
4. 本地识别失败会保留录音，按提示重试或明确选择服务端，不会悄悄上传原始录音。移除语音包可释放手机空间。

3.9.4–3.9.6 新增并修复端侧朗读兼容性。当前端侧包需兼容的 64 位 ARM 设备；不支持的手机仍可用系统或云端语音。对话模型仍在服务器运行。

### 连续语音：分句播报与打断

1. 在语音设置打开自动朗读和连续对话，再从对话右上角“⋯ → 连续语音”进入。
2. 回答形成完整短句后即可开始朗读，后面的文字继续生成。可以调整停顿时长和本地发音人。
3. 点按打断会停止上一轮播报并继续听；耳机开口打断是可选试用，外放使用点按更稳定。
4. “语音快速回答”会请求关闭本轮深度思考，实际速度仍取决于网关、模型和网络。切后台会暂停录音与播报。

3.9.4 新增。端侧语音降低对服务器识别与合成的依赖，不代表所有手机都能达到实时通话延迟。

### 4.0.0 两个版本：功能相同，下载来源不同

1. 在“我的 → 关于”或语音包下载区域确认当前是 GitHub 版还是 OSS 加速版。
2. GitHub 版从模型项目的 GitHub Releases 下载 STT/TTS，并从本 App 的 GitHub Releases 检查更新；OSS 版使用维护者配置的下载服务。
3. 两版使用相同的模型版本、校验值和功能。覆盖安装相同包名、相同签名的版本会保留配置和已安装语音包。
4. 应用内更新只接受当前渠道的安装包。下载完成后仍需通过 Android 系统安装界面确认，不会静默安装。

4.0.0 新增。无需为了升级重新配置服务器、首页或早晚整理。
