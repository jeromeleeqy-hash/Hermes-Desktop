## 聊天頭像與檔案

- 使用者訊息旁顯示設定中的“我的頭像”；未設定時顯示姓名縮寫。與 F1 應用圖示、Hermes 助理頭像分別管理。

## HTML 預覽

- 工作空間與專案篩選合併到左側導航，支援查詢工作空間；收起導航後仍能切換。
- 模型選擇移到聊天輸入框，支援按模型或提供商搜尋。切換中顯示狀態，完成前暫停傳送；延遲返回不會把你帶回上一段對話。
- 檔案入口在重新整理按鈕旁，保留目錄、近期產物、本機草稿、文件分欄和檔案欄拖動調整。

## 輸入與閱讀

- 在“設定 → 對話與記憶”或輸入框下方選擇 Enter 傳送 / Ctrl+Enter 傳送。
- Enter 傳送時，Shift+Enter 換行；Ctrl+Enter 傳送時，Enter 換行。換行保留游標與選區邏輯，輸入法組合輸入時不觸發傳送。
- 修整完整傳送點選區域，統一鍵盤和點選的提交入口。附件準備、模型切換、空內容、停止中等狀態都有明確反饋。
- 已確認被伺服器拒絕的訊息恢復為草稿，可直接重試；未知提交結果先恢復狀態，避免重複執行。
- 任務執行中可排隊、補充指令或停止後傳送。只有伺服器確認停止後，才提交替代任務；佇列可以檢視、改寫和移除。
- 已知的英文模型切換頭轉成簡短中文記錄；等待中斷提示結構化顯示。原始訊息仍保留，引用和程式碼示例不被刪除。
- 助理正文采用輕量閱讀佈局，執行活動預設摺疊，可選擇展開或只看回答；大綱可定位已載入的問題。
- 閱讀舊訊息時保留當前位置；切換對話保留本次執行期間的閱讀位置。重新整理最近訊息時，保留能夠與新結果銜接的已載入歷史。

# Hermes Windows 1.2.0

這一版把工作台變成直接交辦任務的入口，並修復 1.1.0 對話列表無法同步的問題。

## 這次最值得試的變化

- **直接開始任務**：在工作台輸入目標、拖入或選擇附件，點選“開始任務”。草稿按賬號、工作空間和專案儲存。模板會追加到已有文字後，不覆蓋你的輸入。
- **快速查詢**：按 Ctrl K，輸入關鍵詞，用方向鍵選擇、Enter 開啟、Esc 返回。在當前工作空間查詢操作、對話摘要和近期檔案；“搜尋對話內容”進一步搜尋歷史訊息。
- **一眼找到入口**：寬視窗下顯示帶文字的導航和最近對話。Ctrl B 切換導航；聊天中按 Ctrl Shift F 收起輔助區域，切回後保留原來的文件和檔案欄設定。
- **輕一些的介面**：去掉玻璃主題的厚重雙邊框，統一層次和留白。工作台同時展示需要確認的事項、執行中的任務、近期檔案和最近對話。
- **更順手的設定**：限制閱讀寬度，開關整行可以點選，技能列表在寬度足夠時使用兩列。

## 修復與可靠性

對話請求限制為每頁最多 100 條，解決閘道拒絕 limit=200 導致首頁和對話頁報錯的問題。普通對話和歸檔對話都支援分頁；相容無總數、短頁和重疊頁；異常響應不會再當作空工作空間。

同步失敗、正在載入、真正沒有資料分別顯示。失敗時保留已有對話並提供重試和原因入口。訊息載入失敗不再出現新對話歡迎語。搜尋中不再短暫顯示未篩選的全部列表，讀取部分訊息失敗時會明確提示結果可能不完整。

新建對話防重複點選，附件準備完成後才允許傳送。首頁任務轉入對話後先儲存草稿再傳送。舊訊息讀取結果不能覆蓋剛啟動的任務；快速切換工作空間和多次重新整理時，較舊的對話同步結果不會覆蓋較新的結果。

Windows 介面的主要快捷鍵統一顯示 Ctrl。中文輸入法組合輸入期間，Enter 不會觸發首頁傳送或快速查詢確認。

## 升級

已經使用 Windows 1.1.0 便攜版：使用 1.2.0 更新包，按包內說明替換 app/hermes-desktop.jar。它沿用 1.1.0 的其餘依賴和 Java 執行環境。

首次使用或需要完整目錄：完整解壓 1.2.0 portable 包，雙擊 Start-Hermes.bat。不要只複製啟動指令碼；app 和 runtime 必須一起保留。

資料仍在當前 Windows 使用者的 %LOCALAPPDATA%\HermesDesktop。升級不改變使用者資料格式和目錄。建議保留舊版目錄，便於需要時回退。

## 驗證範圍

自動化迴歸使用模擬閘道和演示資料，截圖來自真實 Compose 元件渲染。沒有連線你的生產閘道執行任務，也沒有在 Windows 真機上執行這一包。Windows 通知、語音、麥克風、DPAPI、視窗縮放和 JavaFX 原生視窗仍需要在實際機器上確認。詳細結果見 WINDOWS-VALIDATION.md。
