# Hermes Desktop 2.0.0 · 验收版

与 Android 4.0.0 共用首页协议、服务器记录和事项操作回执。默认简洁首页，可切换深入首页查看关注、待收尾和提醒。

- 支持 6 种卡片布局、20 类交互、事项聊天及结束后的增量同步。
- 首页设置支持早晚整理、实际 Cron 核对、旧版存储迁移；仅优化规则时保留原任务安排。
- 后台维护记录归入首页任务，全部会话入口保留；新增、最近完成和读取顺序独立维护。
- 修复新建空会话首条消息、旧运行 ID、网关就绪竞态、读响应断流、心跳与休眠恢复。
- 授权回答前同步服务器快照；修复跨端处理后的旧请求残留。模型切换兼容 lazy 元数据，明确状态以服务器回读为准。
- 手工会话名称完整保留，允许 1–120 字符。
- 语音识别和朗读独立设置；支持完整句子提前朗读、下一句预取、打断后恢复聆听。
- 可分别下载 SenseVoice 和 Kokoro，支持续传、SHA-256 校验和移除；录音恢复保留原识别引擎。
- 修复 WAV 录音错误标记为 MP4；补充离线连接指南及本机/远程地址说明。

OSS 下载与更新源按要求留到最后处理。本验收版仍使用 GitHub 官方发布下载。

本次在 Linux 构建环境完成自动化与离屏界面检查。Windows/macOS 安装、系统麦克风/音色、休眠唤醒及真实 Hermes 网关联调仍需实机验收；不得将这些项目视为已通过。
