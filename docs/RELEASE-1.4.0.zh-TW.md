# Hermes Windows 1.4.0 · 桌面工作空間

這次根據提供的飛書 PC 端截圖重做視窗、導航和控制元件，保留 Hermes 的對話、任務、文件與閘道能力。參考的是分欄、層級與互動方式，圖示為專案內原創 SVG。

## 啟動與模型選擇

- 模型目錄的載入中、讀取失敗、需要重啟、空目錄和搜尋無結果分別顯示。目錄失敗不會再在進入軟體時彈出英文錯誤，也不清空當前模型與草稿。
- 模型選擇器留在輸入框底部，顯示當前模型、提供商分組、搜尋、選中標記、重新讀取及模型管理入口。切換期間停用重複操作，失敗保留原狀態。
- 對伺服器返回的模型目錄檢查結構，相容字串與物件形式的模型 ID，去重並排除明確未認證的提供商。無效返回不再被當成“沒有模型”。

**截圖裡的實際原因仍需要在伺服器處理：** 伺服器已更新，但正在執行的 Hermes 閘道程序還是舊程式碼，伺服器因此暫時禁止讀取模型目錄。請重啟伺服器上實際執行的 Hermes 閘道服務，完成後在模型選擇器點選“重新讀取”。僅重開 Windows 用戶端不能完成伺服器重啟。這個版本沒有繞過伺服器檢查，也沒有遠端重啟你的伺服器。

## 視窗與佈局

- Windows 預設移除系統標題欄。頂部與應用背景融合，保留拖動區域和最小化、最大化／還原、關閉按鈕；雙擊拖動區域切換最大化。關閉仍執行草稿儲存流程。
- 左側保留個人入口、工作空間、搜尋、對話、工作台、任務與設定。對話列表獨立成欄，支援全部／未讀／置頂、摘要、時間和當前對話選中態。
- 聊天作為獨立面板；窄視窗、專注模式及開啟輔助面板時自動調整分欄。工作空間仍在左側，檔案入口仍在重新整理旁，模型仍在輸入框內。
- 工作台重新整理問候區、任務入口、進度與最近成果。設定採用獨立二級導航、搜尋和扁平分組，縮小開關並統一焦點、懸停與分隔線。

## 三套主題

| 主題 | 設計差異 |
| --- | --- |
| 輕盈辦公（預設） | 淺藍灰外層、白色獨立面板、適中的圓角和清晰的分欄。 |
| 紙間留白 | 紙面紋理、較直的邊角、更窄的閱讀寬度、獨立回覆卡片與更寬的留白。 |
| 流光玻璃 | 藍紫與青色漸變背景、半透明面板、較大的圓角和懸浮層次。 |

三套主題均可選擇淺色／深色、字級和密度。新版第一次採用“輕盈辦公”，之後儲存本次主題選擇；舊偏好資料保留用於回退。

## 細節

- 統一 59 個 SVG 圖示：常規操作使用同一網格與線寬，導航選中態使用雙色圖形，未選中態保留輪廓。檔案按型別顯示圖示與色彩。
- 訊息中的已識別模型執行頭繼續結構化顯示；已解析圖片的開頭傳輸路徑由圖片展示替代，原始訊息與未知文本保留。
- 歷史圖片讀取失敗在訊息內顯示重試與詳情，避免後臺圖片錯誤彈窗打斷工作。
- 保留 Enter／Shift+Enter 和 Ctrl+Enter／Enter 兩套傳送換行規則、滑鼠傳送、排隊、停止、引用、文件編輯和草稿恢復。

## 更新

已有 1.2.0、1.2.1 或 1.3.0 的 Windows x64 便攜版：關閉程式，把舊 `app/hermes-desktop.jar` 備份到 app 目錄之外，然後用 update 包替換這個檔案。首次使用下載完整 portable 包並執行 `Start-Hermes.bat`。使用者資料繼續使用 `%LOCALAPPDATA%\HermesDesktop`。
