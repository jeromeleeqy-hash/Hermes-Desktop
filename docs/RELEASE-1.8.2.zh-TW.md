# Hermes Windows 1.8.2

這次是導航與桌面選單的體驗修復版。

## 導航欄

收窄後，切換工作空間、個人頭像、導航圖示和展開按鈕統一居中。展開導航時，新增最多四條最近對話快捷入口，置頂對話優先；只展示當前工作空間和所選專案中的真實對話。收窄後可通過時鐘圖示選擇最近對話。較矮視窗內列表可滾動，設定和展開按鈕保留在底部。

## 桌面右鍵選單

托盤和懸浮球繼續使用同一套中文字型、圓角、陰影與主題選單。開啟選單後，左鍵點選桌面、工作列或其他程式可收起選單，同時保留原點選操作。全域性監聽僅在選單可見時安裝，關閉後移除；延遲事件不會關掉隨後重新開啟的選單。

修復涉及 Windows 原生滑鼠訊息。構建主機為 Linux，已驗證共享選單的實窗互動和回撥取消邏輯；Windows 系統級滑鼠監聽未在 Windows 真機執行。完整範圍見 WINDOWS-VALIDATION.md，原始碼附獨立程序的 Windows 驗證入口。

## 安裝與原始碼

先在系統托盤選單選擇“退出 Hermes”，再執行 Hermes-Windows-1.8.2-Setup.exe，使用原安裝目錄升級。完整安裝程式自帶 Windows x64 執行環境；配置、頭像、草稿繼續保留。完整原始碼與構建說明見 Hermes-Windows-1.8.2-source.zip。
