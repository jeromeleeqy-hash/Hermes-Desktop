# Hermes Desktop 2.0.1

本次處理 2.0.0 實際使用中的五項反饋。

- 待確認操作改為短標題、獨立的命令閱讀區和固定操作區。命令使用等寬字型，可選中、複製、滾動；長內容不會把允許／拒絕按鈕擠出視窗。聊天、任務中心、小窗使用同一組件。
- 普通訊息被伺服器接收後，只更新對話內狀態，不再彈出“已傳送”。傳送失敗、排隊和需要使用者處理的提示仍保留。
- 首頁模式切換收進“首頁設定”。同步、更新進展與設定放到事項區域，簡潔首頁位於輸入框下方，不再佔據頁面最頂端。
- 首頁詳情支援 Markdown 標題、段落、強調、列表、程式碼與連結。相容舊卡片中的字面換行和【標題】，正文保留完整；僅調整展示，不修改卡片內容、指紋或互動資料。
- 語音設定頂部提供本機 STT／TTS 模型卡片，一鍵下載並啟用；支援進度、暫停續傳、SHA-256 校驗、匯入已下載的模型包、試錄和試聽。

## 使用本機語音

進入“設定 → 語音”，分別在“本機語音識別 · STT”和“本機語音朗讀 · TTS”點選“下載並啟用”。SenseVoice 識別包約 155 MiB，Kokoro 朗讀包約 140 MiB。安裝完成後即可試錄或試聽；兩個引擎可以獨立選擇。

如果應用內下載不便，點選“手動下載”，保留下載到的 `.tar.bz2` 檔案，再用“匯入模型包”選擇它。匯入同樣核對固定的檔案大小與摘要，原始檔案不會被刪除。

模型安裝後，本機試錄和試聽不依賴閘道。語音對話的文字回覆仍需要 Hermes 閘道。本機模型發生錯誤或被移除時會說明原因，不會自動改成伺服器識別或上傳錄音。下載完成時如果正在使用語音，可在結束後啟用，避免中途切換。

## 更新安裝

Mac Apple Silicon：退出正在執行的 Hermes，解壓 `.app.zip`，把其中唯一的 `Hermes.app` 替換到“應用程式”。歸檔內保留可執行許可權和應用結構，不再生成多餘的外層 `.app`。

Windows x64：使用 Setup.exe，或完整解壓便攜包。安裝包與便攜包使用相同應用程式碼和內建執行時。
