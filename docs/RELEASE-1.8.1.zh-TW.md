# Hermes Windows 1.8.1

釋出日期：2026-09-14

## 介面修正版

- 左側導航頂部重新佈局：Hermes 標識與品牌名稱獨立呈現，個人頭像、暱稱和工作空間組成統一的賬戶區域。點選品牌返回工作台，點選個人資料進入外觀與賬戶，工作空間仍可直接切換。
- 托盤和懸浮球右鍵選單統一採用軟體內的字型、圓角、邊框、陰影、圖示及懸停動畫，跟隨主題、深淺模式和文字大小，解決原生選單中文字顯示為方框的問題。
- 選單支援鍵盤選擇、Enter 操作和 Esc 收起；點選外部收起，多個選單互斥。靠近螢幕邊緣時自動調整位置，避開工作列。
- 托盤選單提供開啟 Hermes、懸浮球開關、設定及完整退出；懸浮球選單保留提問、框選截圖、連續語音、開啟主視窗及關閉懸浮球。
- 修正版繼續使用 1.8.1 版本號，提供完整安裝程式及原始碼；覆蓋安裝到原目錄即可。

## 懸浮球按住說話

- 按住滑鼠左鍵約 0.55 秒進入錄音，錄音期間顯示“鬆開滑鼠，識別後傳送”。說話中的短暫停頓不會提前提交。
- 鬆開滑鼠即停止錄音，識別完成後自動傳送到懸浮球當前選擇的對話。此行為不受普通錄音的“自動傳送”偏好影響。
- 鬆開位置可以在懸浮球以外；彈出提問小窗時不會搶走按住手勢的焦點。
- 同一次鬆開只結束一次錄音；識別期間再次長按不會中斷或重複提交上一段語音。
- 回覆完成後等待下一次按住；按住模式不會自動開啟下一輪麥克風。持續語音仍可通過語音按鈕或右鍵選單進入。
- 目標對話正在執行任務時，新的語音問題加入該對話佇列；模型切換或附件讀取未完成時，識別文字保留在草稿中。
- 對話尚未準備好就鬆開時，取消延遲錄音並提示重新按住。關閉小窗、切換對話、關閉懸浮球不會將取消的錄音自動發出；可用錄音保留在原對話的語音記錄中。
- 未識別到內容時不傳送空訊息；識別失敗的錄音可重試。

單次錄音仍沿用最多 60 秒的保護上限；達到上限後停止錄音，仍等鬆開滑鼠才傳送。

## 完整安裝與原始碼

- 應用、啟動器與安裝程式統一為 1.8.1；沿用已確認的 C1 圖示。
- 合併 1.8.0 啟動修復：執行環境補齊桌面互操作模組，啟動前檢查實際模組，並將兩路 JVM 輸出寫入同一完整日誌。
- 提供完整 Setup 安裝包及完整原始碼包。安裝包內含 Windows x64 執行環境，不需要另裝 Java。
- 原始碼包含構建、測試、資源及安裝打包指令碼；可直接從已連結的 Windows 執行環境打包，不依賴舊版便攜包。

## 升級

在 Windows 右下角系統托盤中右鍵 Hermes，選擇“退出 Hermes”，再執行 `Hermes-Windows-1.8.1-Setup.exe`，沿用原安裝位置。使用者配置、頭像、對話快取和草稿繼續使用原資料目錄，無需解除安裝。
