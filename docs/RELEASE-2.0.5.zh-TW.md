# Hermes Desktop 2.0.5 · 檔案定位修復

有些回覆只寫檔名，實際檔案卻儲存在工作目錄的子目錄中。2.0.3 修復了相對路徑截斷，但沒有覆蓋這種缺少目錄的連結。

- 點選僅含檔名的連結或卡片時，優先採用原回覆中的完整位置；直接讀取失敗後，在來源對話的工作目錄及子目錄中查詢。
- 完整查詢後只有一個匹配檔案才自動開啟；多個同名檔案顯示完整路徑供選擇。
- 超時、許可權不足或目錄數量超過限制時，說明查詢未完成，不把不完整結果當成唯一匹配，也不直接聲稱檔案已刪除。
- 記住實際讀取成功的路徑，後續點選、重新整理檔案索引和重啟後繼續使用；檔案移動後可在原範圍重新查詢。
- 增加貼上伺服器完整路徑開啟和複製排查資訊。長候選列表可滾動，底部按鈕固定可見。

查詢只使用現有檔案讀取介面，最多 128 個目錄、20,000 個專案、約 10 秒，不執行伺服器命令，不修改檔案或對話。目錄過大時可直接貼上完整路徑。
