# Hermes Desktop 2.0.3

本次修复对话生成文件无法打开的问题。

- 相对路径保留首级目录，例如 `03_主题/活动/项目.md`；按来源会话的服务器工作目录读取。
- 支持代码片段或引号中的中文、空格、括号文件名，保留 Windows 盘符与网络共享路径。
- 避免对已解析路径重复解码，保留文件名中的加号、井号与百分号。
- 重新整理历史文件索引；旧文件卡片读取原消息恢复完整路径，遇到同名歧义时不猜选文件。
- 不修改服务器目录、会话内容或已有文件。

## 安装

macOS Apple Silicon：退出旧版，解压 app.zip，将 Hermes.app 替换到“应用程序”。
Windows x64：退出旧版后运行 Setup.exe，或完整解压便携 ZIP 使用。
请手动下载安装；旧版自动更新器只识别 MSI / DMG。
