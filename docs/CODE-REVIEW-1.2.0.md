# 1.2.0 代码检查与处理记录

检查依据：1.1.0 源码和用户提供的实际 Windows 截图。实现范围覆盖 API 列表读取、桌面状态控制、工作台、主导航、聊天输入、快速查找和设置。

| 问题 | 处理 | 验证 |
|---|---|---|
| 前端请求 200 条会话，网关上限为 100 | API 层限制每页 100，统一普通与归档会话分页 | 模拟网关实际拒绝 200 的协议回归 |
| 缺少总数时只读取一页 | 根据实际页长度续读，支持显式总数的短页 | 125 条、短页和重叠页用例 |
| 重复页可能循环；异常 JSON 被当作空列表 | 重复页和异常结构明确失败 | 重复页、错误结构、空页与剩余总数用例 |
| 失败时同时出现“没有会话” | 加载、错误、空状态分离，保留已读数据 | home-error / home-loading 渲染断言 |
| 原始校验 JSON 直接暴露在页面 | 提取错误描述，页面显示可操作提示，原因按需查看 | 校验数组回归和错误画面检查 |
| 旧刷新结果可能覆盖新结果 | 同步请求使用递增序号，只接受当前结果 | 代码路径检查 |
| 旧消息加载可能覆盖刚发送的一轮 | 启动新任务时使旧读取结果失效 | 代码路径检查；已有任务恢复回归 |
| 新建会话连续点击可能重复提交 | 创建期间禁止重复调用；失败解除忙碌状态 | 代码路径检查 |
| 首页附件没有明确归属 | 首页草稿和附件按工作空间、项目分组；创建成功后一起转移 | WorkbenchTest 与实际 UI 操作 |
| 附件尚在转换时可能提前发送 | 转换期间阻止首页与聊天发送 | 草稿/附件回归 |
| 搜索等待阶段出现全部会话；读取失败被吞掉 | 等待立即显示，部分失败明确提示 | 代码路径检查 |
| 设置行太宽、开关只能点小区域 | 限制内容宽度，整行开关和可访问语义；技能响应式两列 | 设置页面与 1.5×/2× 渲染 |

新增首页模板只填入文字，不绕过用户的发送操作。已输入内容不被模板覆盖。

## 本轮没有宣称覆盖的内容

没有操作生产网关、真实麦克风或 Windows 桌面。Windows 真机启动、系统通知、DPAPI 和 JavaFX 本地窗口仍需实际运行确认。既有全文搜索范围仍为最近最多 100 段会话、每段最近 200 条消息；快速查找先使用当前工作空间已同步的内容。

没有更换服务端执行、权限审批、远程文件写前校验和用户数据加密方案。它们沿用原有实现和回归检查。
