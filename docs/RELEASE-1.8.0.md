# Hermes Windows 1.8.0

本轮使用已选定的 C1 图标，集中处理文件预览、后台运行和桌面快捷提问。

## 文件预览

- Word（DOC / DOCX）与 Excel（XLS / XLSX）增加独立的本地兼容渲染器，网页组件启动失败不会再让这两类文件整页空白。保留正文、表格、工作表切换、分页、合并单元格及常见嵌入图片。
- HTML 继续使用隔离的静态网页预览；网页组件不可用时自动显示兼容预览，可重新尝试网页组件或查看源码。
- Windows 启动脚本明确装载 JavaFX 模块，预览初始化错误写入启动日志，便于定位运行环境问题。
- 修正文档嵌入窗口时可能被绘制层遮挡的问题，兼容使用软件渲染的电脑。
- PPT / PPTX / PDF 支持翻页、缩略图、缩放及文字阅读；页面排版失败时显示可提取的文字。
- Office 为只读预览。复杂图表、嵌入对象、特殊字体、幻灯片动画和部分旧文档排版可能与 Office 原软件不同；保留下载入口。HTML 预览不执行页面脚本。

## 后台与托盘

- 点击主窗口右上角关闭按钮，会收起到系统托盘，任务、回复接收和草稿保存继续工作。
- 左键点击托盘图标恢复主窗口；右键菜单可以打开主窗口、切换悬浮球，或选择“退出 Hermes”完整退出。
- 系统托盘不可用时，关闭按钮退回为最小化，避免窗口消失后无法找回。
- 升级和卸载前，请通过托盘菜单完整退出。

## 桌面悬浮球

- 与软件使用同一 C1 图标，位于普通桌面窗口之上，拖动后记住位置。
- 单击打开独立提问小窗，每次新打开默认进入“日常助理”；小窗可以搜索和切换会话。
- 拖入文件后加入当前小窗会话的附件草稿，输入问题后发送。也支持文件选择和粘贴附件。
- 双击进入框选截图。拖动选择范围，松开后加入附件；Esc 或右键取消。
- 长按左键进入连续语音对话。识别结果发给小窗所选会话，沿用已有语音识别与朗读配置；界面显示录音、识别、回应和朗读状态。
- 文字、文件、截图和语音绑定到小窗会话，不会因主窗口停在另一个会话而误发。
- 单击、双击、长按与移动共用手势判定；加入悬停、缩放、文件拖入高亮及语音呼吸动画，并尊重“减少动态效果”设置。
- 设置 → 桌面助手，可以即时开关悬浮球。
- 关闭小窗保留草稿和任务；关闭连续语音会停止继续聆听。

## 安装与更新

推荐直接使用 `Hermes-Windows-1.8.0-Setup.exe`。已有安装可在完全退出旧版后升级，用户配置、头像与草稿保存在原用户数据目录。

便携版需要完整解压后运行 `Hermes.exe`。更新包必须替换整个 `app` 目录以及本包的 `Hermes.exe`、`Start-Hermes.bat` 和 `Diagnose-Hermes.bat`，保留已有 Windows Java 21 `runtime`。只覆盖主 JAR 或沿用旧启动脚本不构成完整升级。

## 验证说明

构建环境为 Linux。自动测试、真实文档渲染及桌面小窗验证记录见 `WINDOWS-VALIDATION.md`。Windows 托盘、系统麦克风、真实多屏 DPI 与真实网关仍需要在 Windows 电脑上验收；安装包未进行 Windows 代码签名。
