# Hermes Windows 1.8.3

本次修復六項互動與閘道相容問題。

1. 圖片與截圖附件可直接點選名稱預覽，支援縮放、拖動和原始大小檢視。主聊天、工作台和浮窗使用同一組件，獨立 × 按鈕負責刪除。預覽讀取草稿已有位元組，不會提前上傳或清空草稿；常見文本、PDF、表格、簡報也可檢視，其他格式可儲存到本機。
2. 思考文本保留閘道傳送的英文空格、換行和縮排，修復流式片段 trim 導致的單詞粘連。已由舊版本儲存為粘連文本的歷史內容無法可靠自動補回空格。
3. 工作台最後一條最近對話不再顯示下方橫線。
4. 桌面懸浮球右鍵選單、托盤選單和快速提問窗使用柔和陰影及更寬的透明邊距。
5. 截圖覆蓋層改為可獲取焦點的工具視窗。Esc、右鍵、視窗關閉與截圖結束均釋放鍵盤監聽並恢復浮窗。
6. 新舊閘道確認協議相容。新版伺服器端 JSON-RPC 的 clarify / approval 請求以原始 id 回應；舊版事件繼續使用 clarify.respond / approval.respond。支援多問題、多選、自定義回答、鎖定答案恢復、取消通知以及重連後的待確認事項恢復。主聊天和浮窗可直接開啟確認面板，任務中心同步顯示。遇到 session busy 會保留本次輸入並嘗試恢復伺服器任務。

## 安裝

在托盤選單選擇“退出 Hermes”，執行 Hermes-Windows-1.8.3-Setup.exe，使用原安裝目錄升級。無需解除安裝、無需另裝 Java。賬號配置、頭像和草稿繼續儲存在原使用者目錄。

## 協議依據

實現對照 NousResearch/hermes-agent 的 tui_gateway/server.py 與 tui_gateway/server_requests.py（2026-09-15 檢查）。請求恢復依賴閘道實際提供 open_requests 或舊版 pending 欄位。伺服器本身未發出請求且不提供恢復欄位時，用戶端不能還原缺失選項；仍可停止任務。

## 驗證範圍

本次驗證記錄見 WINDOWS-VALIDATION.md。構建與自動化在 Linux 主機進行，Windows 系統桌面、安裝升級和使用者實際閘道需實機驗證。
