## Beta 2 登录回归

本次在 Linux + JDK 21 上重新编译主程序并运行全部 82 项测试，0 失败、0 错误、0 跳过。新增 `GatewayLoginTest` 的 9 项检查通过真实本地 HTTP 服务与实际加密 Cookie 存储验证：

- 密码中的前后空格、引号、反斜杠、加号、中文、重音字符和 Emoji 按原文提交；请求字段及 JSON 编码与网关接口一致。
- 登录返回的 Cookie 用于 `/api/auth/me`，重建客户端后可恢复已有登录状态；支持网关路径前缀。
- 空账号／密码在网络请求之前被拒绝。
- 提交密码时被拒绝、提交后会话验证失败、恢复旧会话失败有不同的失败阶段。
- 401 认证拒绝与 429 限流不会重复提交密码。
- 登录方式接口返回非 JSON 时不发送密码。
- 诊断不包含原始服务器响应，即便错误响应回显敏感内容也不会进入弹窗或诊断；本机存储错误有独立分类。

实际 Compose 代码另渲染了 1440×900 和 1160×760 两种登录页，检查了新增“显示”按钮、禁用的空密码提交按钮与客户端版本。截图见 `docs/previews/login-beta2.png` 和 `login-narrow-beta2.png`。已有八张功能页面截图来自 Beta 1，此次未重渲染。

当前仍没有用户网关的现场 HTTP 结果，未复现其第一次 `Invalid credentials`，也未验证 Mac 上的密码输入法与实际登录。用户已确认上一版在 Mac 上编译成功；本次登录更新仍需在该设备运行复测。测试通过不等同于已解决真实网关认证。
