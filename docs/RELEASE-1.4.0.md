# Hermes Windows 1.4.0 · 桌面工作空间

这次根据提供的飞书 PC 端截图重做窗口、导航和控件，保留 Hermes 的对话、任务、文档与网关能力。参考的是分栏、层级与交互方式，图标为项目内原创 SVG。

## 启动与模型选择

- 模型目录的加载中、读取失败、需要重启、空目录和搜索无结果分别显示。目录失败不会再在进入软件时弹出英文错误，也不清空当前模型与草稿。
- 模型选择器留在输入框底部，显示当前模型、提供商分组、搜索、选中标记、重新读取及模型管理入口。切换期间禁用重复操作，失败保留原状态。
- 对服务器返回的模型目录检查结构，兼容字符串与对象形式的模型 ID，去重并排除明确未认证的提供商。无效返回不再被当成“没有模型”。

**截图里的实际原因仍需要在服务器处理：** 服务器已更新，但正在运行的 Hermes 网关进程还是旧代码，服务器因此暂时禁止读取模型目录。请重启服务器上实际运行的 Hermes 网关服务，完成后在模型选择器点击“重新读取”。仅重开 Windows 客户端不能完成服务器重启。这个版本没有绕过服务器检查，也没有远程重启你的服务器。

## 窗口与布局

- Windows 默认移除系统标题栏。顶部与应用背景融合，保留拖动区域和最小化、最大化／还原、关闭按钮；双击拖动区域切换最大化。关闭仍执行草稿保存流程。
- 左侧保留个人入口、工作空间、搜索、会话、工作台、任务与设置。会话列表独立成栏，支持全部／未读／置顶、摘要、时间和当前会话选中态。
- 聊天作为独立面板；窄窗口、专注模式及打开辅助面板时自动调整分栏。工作空间仍在左侧，文件入口仍在刷新旁，模型仍在输入框内。
- 工作台重新整理问候区、任务入口、进度与最近成果。设置采用独立二级导航、搜索和扁平分组，缩小开关并统一焦点、悬停与分隔线。

## 三套主题

| 主题 | 设计差异 |
| --- | --- |
| 轻盈办公（默认） | 浅蓝灰外层、白色独立面板、适中的圆角和清晰的分栏。 |
| 纸间留白 | 纸面纹理、较直的边角、更窄的阅读宽度、独立回复卡片与更宽的留白。 |
| 流光玻璃 | 蓝紫与青色渐变背景、半透明面板、较大的圆角和悬浮层次。 |

三套主题均可选择浅色／深色、字号和密度。新版第一次采用“轻盈办公”，之后保存本次主题选择；旧偏好数据保留用于回退。

## 细节

- 统一 59 个 SVG 图标：常规操作使用同一网格与线宽，导航选中态使用双色图形，未选中态保留轮廓。文件按类型显示图标与色彩。
- 消息中的已识别模型运行头继续结构化显示；已解析图片的开头传输路径由图片展示替代，原始消息与未知文本保留。
- 历史图片读取失败在消息内显示重试与详情，避免后台图片错误弹窗打断工作。
- 保留 Enter／Shift+Enter 和 Ctrl+Enter／Enter 两套发送换行规则、鼠标发送、排队、停止、引用、文档编辑和草稿恢复。

## 更新

已有 1.2.0、1.2.1 或 1.3.0 的 Windows x64 便携版：关闭程序，把旧 `app/hermes-desktop.jar` 备份到 app 目录之外，然后用 update 包替换这个文件。首次使用下载完整 portable 包并运行 `Start-Hermes.bat`。用户数据继续使用 `%LOCALAPPDATA%\HermesDesktop`。

## 验证范围

实际编译、HTTP／WebSocket 回归、Compose 鼠标与键盘测试、真实组件多尺寸截图的记录见 `WINDOWS-VALIDATION.md`。本轮环境为 Linux，未连接用户生产网关，未在 Windows 真机运行本包；原生窗口拖动与缩放、系统语音、通知、DPAPI 及 JavaFX 仍需在 Windows 确认。
