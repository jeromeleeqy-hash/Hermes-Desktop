# Hermes Windows 1.8.2

在右下角系統托盤右鍵 Hermes → 退出 Hermes，然後執行 `Hermes-Windows-1.8.2-Setup.exe`，使用原安裝目錄即可升級。無需另裝 Java。使用者配置、頭像和草稿繼續儲存在 `%LOCALAPPDATA%\HermesDesktop`。

便攜版完整解壓到新目錄後執行 `Hermes.exe`。請使用包內完整執行環境和啟動檔案，不要只覆蓋主 JAR，或混用舊依賴。1.8.2 已合併啟動修復。

- **懸浮球：**設定 → 桌面助手，可開關懸浮球。單擊提問、雙擊框選截圖，拖入檔案可新增附件。按住左鍵約 0.55 秒開始說話，鬆開後識別併傳送；回覆後等待下一次按住。右鍵選單中的“連續語音”仍可持續對話。
- **後臺：**關閉主視窗後程序留在系統托盤，正在執行的任務繼續執行；托盤右鍵 → 退出 Hermes，才會完整退出。
- **供應商：**設定 → 模型供應商。可填寫常用 API Key，也可新增自定義端點。已儲存的金鑰不回顯，編輯自定義供應商時留空保留金鑰。
- **頭像：**設定 → 外觀與賬戶 → 我的頭像。使用者訊息右側顯示該頭像；助理頭像獨立配置。
- **檔案：**點選輸入框的新增檔案，或拖入檔案、複製檔案後 Ctrl+V 貼上。先看到附件條目，再傳送。失敗會提示原因並保留草稿。每次最多 10 個，圖片最多 8 MB，其他檔案最多 12 MB。
- **Markdown：**檔案頁支援閱讀、編輯與雙欄；雙欄工具條可切換同步/獨立滾動。Ctrl+F 查詢，Ctrl+H 替換。
- **HTML：**靜態預覽，支援工作空間相對圖片和 CSS。載入時可切到原始碼；網頁尾本和動畫不執行。
- **其他預覽：**圖片可縮放、平移、旋轉；PDF/PPT 可跳頁和檢視縮圖；Excel 支援工作表、分頁和合並單元格；Word 支援段落、圖片與表格。

Office 為本機只讀預覽，不保證複雜分頁、字型、圖表和動畫與 Microsoft Office 一致。需要原生效果時可下載到本機開啟。啟動失敗時執行 `Diagnose-Hermes.bat`，日誌位於 `%LOCALAPPDATA%\HermesDesktop\logs`。

安裝包尚未程式碼簽名。自動化在 Linux 執行；Windows 原生互動和 JavaFX 嵌入的驗證範圍見 `WINDOWS-VALIDATION.md`。
