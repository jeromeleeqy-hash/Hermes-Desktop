# Hermes Desktop 2.0.0 验收清单

本次以 Android 4.0.0 正式发布源码为功能依据，在 Desktop 1.9.0（50b71c5d）上升级。使用原来的同一台 Hermes 服务器和 Profiles，首页与业务记录仍由服务器 JSON／Markdown 保存。

## 安装与首次使用

- Windows x64：退出托盘里的旧版 Hermes，再运行 `Hermes-Windows-x64-2.0.0-Setup.exe`。也可将便携 ZIP 完整解压到新目录后运行 Hermes.exe。保留完整 app、runtime 目录，无需另外安装 Java。
- Mac M 系列（macOS 13 或更新）：退出旧版，解压 `Hermes-macOS-arm64-2.0.0.app.zip`，将 **Hermes.app** 放到“应用程序”。2026-10-08 打包修订 r2 的 ZIP 顶层只有这个应用。若旧包解压后得到名为 `Hermes-macOS-arm64-2.0.0` 的异常应用，右键“显示包内容”，如内有 `Hermes.app`，取出内层应用使用。系统首次拦截时，确认文件来自本次验收包后，在“隐私与安全性”中允许打开。应用使用 ad-hoc 签名，未作 Developer ID 公证。
- 沿用原网关地址、账号和 Profile。若旧版安装目录来自 MSI／jpackage，Windows 验收安装器可能安装在新的应用目录；验证通过后再处理旧入口。不会自动删除旧安装或用户数据。
- 先在首页点“同步首页”，读取移动端已有内容；需要更新旧规则时再点“首页设置 → 优化已有首页和整理规则”。
- 本地语音包首次下载约 155 MB + 140 MB，建议预留至少 800 MB 空间。识别、朗读可分别选择本机／服务端／系统方式。

## 功能与验收步骤

下列“待实机确认”是需要在你的真实电脑和服务器上执行的步骤，不代表已经完成真机测试。

| 范围 | 已实现 | 待实机确认的步骤与预期 |
|---|---|---|
| 两种首页 | 简洁首页／深入首页，选择持久保存 | 切换、退出重开后保持；深入页可按关注中、待收尾、提醒和领域筛选 |
| 手机／PC 共享 | 读取同一工作区的首页 JSON；旧路径兼容 | 手机上更新一张卡，PC 同步后看到相同事实和状态；切换 Profile 不串数据 |
| 卡片展示 | 6 种布局，来源、口径、时间、最近完成 | 打开包含进度／指标／日程的卡，检查文字、来源和日期；缩小窗口／放大字号仍可滚动阅读 |
| 卡片处理 | 20 类交互，输入校验、操作 ID、服务器回执 | 选一项可撤销的测试操作提交一次；双击不重复提交；只有服务器回执核实后显示完成 |
| 事项聊天 | 卡片背景带入对话；结束后增量核对 | 从“聊聊这件事”进入，提供真实进展；完成后首页更新；仅聊天不把事项自动标成业务完成 |
| 断线恢复 | 保留操作和草稿，显式“恢复原操作” | 提交后断网再恢复：先同步核对，查看原任务，不新开重复业务任务；重启后仍能看到待核对状态 |
| 首页规则 | 优化规则、早晚任务与实际 Cron 核对 | 保存 09:00／21:00 和时区后核对实际任务；重复保存不增加重复 Cron；优化规则保留已有安排 |
| 旧文件收纳 | 显式迁移、冲突时保留两份 | 仅有旧路径时出现收纳入口；迁移后原业务 Markdown 和任务安排不变；已有新路径无需迁移 |
| 后台任务 | 首页维护任务归类，全部会话可查看 | 首页任务在任务中心可查，普通会话列表不被维护记录占满；切到全部会话仍能找回记录 |
| 连接与发送 | 就绪握手、心跳、前台／休眠感知、读响应重试 | 新建空会话直接发第一句；断网／唤醒后再发；不出现长期卡住；不确定的写请求不自动重发 |
| 跨端授权 | 回答前同步待处理快照 | 手机上批准后 PC 旧请求消失；不能对过期或已变更的请求继续提交旧答案 |
| 模型／思考强度 | lazy 元数据兼容，实际回读优先 | 切换模型后发两轮，重新进入仍正确；思考档位仅展示服务端支持的选择 |
| 名称与草稿 | 保留 1–120 字符手工标题和录音引擎 | 长标题、标点及链接重新载入不被截短；关闭重开后草稿／附件／待转写录音可恢复 |
| 本地语音 | SenseVoice／Kokoro 下载、续传、校验、移除 | 下载中暂停再继续；切到本地识别和朗读，测试中文；拔掉网络仍可进行本机识别／朗读（Agent 对话仍需服务器连接） |
| 连续语音 | 完整句提前播放、预取、打断、恢复聆听 | 长回复先朗读完整句；点打断后旧音频立即停止；下一轮无上轮残留句子；系统麦克风授权正常 |
| 连接帮助 | 内置离线指南、诊断摘要 | 未连接时可打开指南；远程服务器不使用本机 localhost；诊断不输出口令或聊天内容 |
| OSS | 按要求后置 | 本轮使用官方 GitHub 下载源，待验收后再配置 OSS 地址、清单及更新渠道 |

## 已完成验证

- JVM／MockWebServer／Compose 自动回归：346 项，339 通过，0 失败，7 项因需要原生桌面环境而跳过。
- Android 同源首页 writer 的 Python 测试：10 项全部通过。
- 9 个离屏界面：简洁、深入、窄窗口大字号、纸间留白、流光玻璃、深色、首页设置、会议分工交互、语音设置。
- 真实语音模型校验、解包与 JNI 推理：Kokoro 生成 157,706 字节 WAV，SenseVoice 准确识别为“你好，这是桌面版的本地语音测试。”；该验证在 Linux CPU 上执行。
- Windows：对应平台应用依赖、x64 Java 21 运行时与模块、NSIS 载荷逐文件摘要；Mac：Apple Silicon 依赖、应用版本／入口、可执行权限、重新签名后的资源摘要。打包结果另附 SHA256SUMS 与构建清单。

## 尚未验证的边界

当前构建机为 Linux。没有将 Windows／macOS 安装启动、实际麦克风和扬声器、系统语音音色、托盘／菜单栏、系统休眠唤醒、真实 Hermes 服务端的业务执行标记为通过。优先按上表检查连接、共享首页、操作回执和语音，再验收外观与偏好。
