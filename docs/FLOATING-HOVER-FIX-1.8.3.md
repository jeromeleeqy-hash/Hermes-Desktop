# 1.8.3 悬浮球悬停防闪烁修订（2026-09-16）

本包已将修订整合到完整源码，无需手动粘贴补丁。版本号保持 1.8.3。

## 修改
- 保留固定 84×84 窗口，添加固定低透明度绘制底层，避免鼠标命中区域跟随图标透明像素变化。
- 悬停状态按屏幕坐标和固定窗口边界判断，不再直接相信原生 mouseEntered/mouseExited。
- 移除可能遮挡悬浮球的系统 Tooltip，保留无障碍操作描述。
- 悬停稳定后低频检查鼠标位置，隐藏/截图时停止动画并清理悬停状态。
- 单击、双击、长按语音、拖动和右键菜单的手势分发保持原实现。
