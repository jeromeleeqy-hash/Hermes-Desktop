# Hermes Desktop 2.0.2 验收

自动化覆盖：跨设备新消息、旧消息数量/分页、前台定时同步、窗口恢复、手动刷新、加载历史后的同步、失败保留与重试、草稿/附件保留、流式回复并发保护、默认启动工作台、模块进入/返回、8 个最近会话、未读范围、通知会话路由与账号隔离、JNA Blocks 回调参数。

实际桌面界面截图位于 docs/previews/desktop-2.0.2。测试报告和构建校验保存在 docs/validation。

Mac 本机验收步骤：

1. 解压并将 Hermes.app 放入“应用程序”，退出旧进程后打开，确认先进入工作台。
2. 打开“值得留意的事”，再返回工作台；确认没有两种首页模式切换。
3. 在两端打开同一工作空间、同一会话，手机发送一轮；电脑保持前台或切回窗口，核对新增消息出现。
4. 在未查看的会话中产生新回复，检查列表“未读”和侧栏数字；打开并成功读取后应清除。
5. 在设置中发送测试通知，允许 Hermes 的系统通知；点击新产生的通知应打开 Hermes。后台会话回复通知应打开对应会话。旧版已经发出的 AppleScript 通知无法被新版改写，请用新版产生的通知验证。

当前 Linux 构建环境不能操作 Mac 通知中心，原生通知展示/点击没有真机验收记录。Windows 原生启动也需对应系统验证。

本次结果：54 项相关 JVM/HTTP/Compose/回调测试通过，17 项 Python 测试通过；3 张真实 Compose 界面截图已核对。
