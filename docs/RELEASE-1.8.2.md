# Hermes Windows 1.8.2

这次是导航与桌面菜单的体验修复版。

## 导航栏

收窄后，切换工作空间、个人头像、导航图标和展开按钮统一居中。展开导航时，新增最多四条最近会话快捷入口，置顶会话优先；只展示当前工作空间和所选项目中的真实会话。收窄后可通过时钟图标选择最近会话。较矮窗口内列表可滚动，设置和展开按钮保留在底部。

## 桌面右键菜单

托盘和悬浮球继续使用同一套中文字体、圆角、阴影与主题菜单。打开菜单后，左键点击桌面、任务栏或其他程序可收起菜单，同时保留原点击操作。全局监听仅在菜单可见时安装，关闭后移除；延迟事件不会关掉随后重新打开的菜单。

修复涉及 Windows 原生鼠标消息。构建主机为 Linux，已验证共享菜单的实窗交互和回调取消逻辑；Windows 系统级鼠标监听未在 Windows 真机执行。完整范围见 WINDOWS-VALIDATION.md，源码附独立进程的 Windows 验证入口。

## 安装与源码

先在系统托盘菜单选择“退出 Hermes”，再运行 Hermes-Windows-1.8.2-Setup.exe，使用原安装目录升级。完整安装程序自带 Windows x64 运行环境；配置、头像、草稿继续保留。完整源码与构建说明见 Hermes-Windows-1.8.2-source.zip。
