# Hermes Windows 1.3.0 · 體驗重構

這一版圍繞“切換工作空間、開始對話、跟進執行、繼續處理成果”重新組織介面，延續現有閘道、專案和資料目錄。

## 導航與視覺

- 工作空間與專案篩選合併到左側導航，支援查詢工作空間；收起導航後仍能切換。
- 模型選擇移到聊天輸入框，支援按模型或提供商搜尋。切換中顯示狀態，完成前暫停傳送；延遲返回不會把你帶回上一段對話。
- 檔案入口在重新整理按鈕旁，保留目錄、近期產物、本機草稿、文件分欄和檔案欄拖動調整。
- 重繪 52 個 SVG 圖示，統一線條、尺寸和按鈕狀態。三套主題、深色模式、密度與字級選擇繼續保留。

## 輸入與閱讀

- 在“設定 → 對話與記憶”或輸入框下方選擇 Enter 傳送 / Ctrl+Enter 傳送。
- Enter 傳送時，Shift+Enter 換行；Ctrl+Enter 傳送時，Enter 換行。換行保留游標與選區邏輯，輸入法組合輸入時不觸發傳送。
- 修整完整傳送點選區域，統一鍵盤和點選的提交入口。附件準備、模型切換、空內容、停止中等狀態都有明確反饋。
- 已確認被伺服器拒絕的訊息恢復為草稿，可直接重試；未知提交結果先恢復狀態，避免重複執行。
- 任務執行中可排隊、補充指令或停止後傳送。只有伺服器確認停止後，才提交替代任務；佇列可以檢視、改寫和移除。
- 已知的英文模型切換頭轉成簡短中文記錄；等待中斷提示結構化顯示。原始訊息仍保留，引用和程式碼示例不被刪除。
- 助理正文采用輕量閱讀佈局，執行活動預設摺疊，可選擇展開或只看回答；大綱可定位已載入的問題。
- 閱讀舊訊息時保留當前位置；切換對話保留本次執行期間的閱讀位置。重新整理最近訊息時，保留能夠與新結果銜接的已載入歷史。

## 對話、成果與設定

- 側邊欄按置頂、今天、昨天和更早分組；完整對話頁增加置頂、未讀、執行中篩選，並提供清除篩選。
- 任務完成項連線原對話和已索引的檔案，產物引用隨本機完成記錄儲存。
- 檔案根據型別顯示圖示；檔案閱讀、編輯、修改對比和未儲存草稿流程繼續保留。
- 本機輸入與閱讀選項可獨立使用，伺服器配置讀取失敗不會擋住這些設定。
- 提供商目錄可以搜尋、展開；Skills、工具集、MCP 採用統一狀態與詳情層次。MCP 已配置、已啟用與工具數量分別呈現。
- 閘道診斷分別檢查 HTTP、登入、即時連線、對話讀取和檔案能力，顯示各項結果並支援複製診斷。
- 保留 1.2.1 的對話分頁修復：每頁最多 100 條，空頁正確結束，後續頁失敗保留已載入內容。

## 使用與升級

已有 Windows 1.2.0 / 1.2.1 便攜版：關閉 Hermes，將舊的 `app/hermes-desktop.jar` 備份到 app 目錄外，再用更新包同名檔案替換。其餘 66 個依賴逐位元組核對一致。

首次使用或希望直接解壓執行：使用完整 portable 包，完整解壓後雙擊 `Start-Hermes.bat`。已包含 Windows x64 Java 21，無需自行安裝 Java。

本機資料繼續使用 `%LOCALAPPDATA%\HermesDesktop`，不需要清除登入狀態或草稿。原始碼包包含原始碼、構建指令碼、圖示生成指令碼、測試與驗證記錄。

## 驗證範圍

自動化測試 151 項：149 項通過，2 項 Windows DPAPI 原生測試因平臺條件跳過。新增 9 項使用真實 Compose 元件、滑鼠/鍵盤事件、控制器和本機 WebSocket 閘道驗證傳送、重試、排隊、停止和模型切換。

介面截圖來自實際 Compose 渲染與演示資料，覆蓋三種主題、深色、窄視窗、分欄與常見縮放比例。構建與測試在 Linux 完成，尚未在 Windows 真機或你的生產閘道執行本包。語音、麥克風、通知、DPAPI 和 JavaFX 原生視窗仍需實際 Windows 環境確認。
