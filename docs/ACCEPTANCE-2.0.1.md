## 安装包检查

Mac 使用用户已确认能打开的 2.0.0 应用作为原生运行时来源，全部应用 JAR 来自本次构建。打包脚本逐项验证架构、JAR、签名代码页、资源封印、权限、ZIP CRC 与唯一 `Hermes.app/` 顶层目录；任一失败不产出交付包。

Windows 使用同一份 JVM 主程序和真正的 Windows x64 原生依赖；启动器重新编译。便携包核对完整运行时的模块与摘要，安装器校验同一便携包全部 JAR 和运行时文件再编译。

## 需要在你的电脑确认

- 退出旧版后替换／安装 2.0.1，双击启动；旧配置、会话与首页正常恢复。
- 打开实际的长命令待确认请求，滚动阅读，核对允许、拒绝和稍后处理。
- 发送普通消息不再弹“已发送”；发送失败仍有提示。
- 首页设置可切换模式；真实卡片详情标题、列表和完整正文正常。
- “设置 → 语音”下载并启用 STT／TTS，试录、试听；允许系统麦克风权限，核对实际设备输出。
- 断开网关后，本地试录／试听仍可用；恢复网关后语音聊天正常。

本次没有在 Windows 或 macOS 真机上执行新版本。Mac 2.0.0 已获用户启动确认，不等同于 2.0.1 的真机验收。真实网关、原生权限、休眠唤醒和物理音频设备不在此次 Linux 检查结论内。
