# Hermes Windows 1.2.0

这一版把工作台变成直接交办任务的入口，并修复 1.1.0 会话列表无法同步的问题。

## 这次最值得试的变化

- **直接开始任务**：在工作台输入目标、拖入或选择附件，点击“开始任务”。草稿按账号、工作空间和项目保存。模板会追加到已有文字后，不覆盖你的输入。
- **快速查找**：按 Ctrl K，输入关键词，用方向键选择、Enter 打开、Esc 返回。在当前工作空间查找操作、会话摘要和近期文件；“搜索会话内容”进一步搜索历史消息。
- **一眼找到入口**：宽窗口下显示带文字的导航和最近会话。Ctrl B 切换导航；聊天中按 Ctrl Shift F 收起辅助区域，切回后保留原来的文档和文件栏设置。
- **轻一些的界面**：去掉玻璃主题的厚重双边框，统一层次和留白。工作台同时展示需要确认的事项、执行中的任务、近期文件和最近对话。
- **更顺手的设置**：限制阅读宽度，开关整行可以点击，技能列表在宽度足够时使用两列。

## 修复与可靠性

会话请求限制为每页最多 100 条，解决网关拒绝 limit=200 导致首页和会话页报错的问题。普通会话和归档会话都支持分页；兼容无总数、短页和重叠页；异常响应不会再当作空工作空间。

同步失败、正在加载、真正没有数据分别显示。失败时保留已有会话并提供重试和原因入口。消息加载失败不再出现新会话欢迎语。搜索中不再短暂显示未筛选的全部列表，读取部分消息失败时会明确提示结果可能不完整。

新建会话防重复点击，附件准备完成后才允许发送。首页任务转入会话后先保存草稿再发送。旧消息读取结果不能覆盖刚启动的任务；快速切换工作空间和多次刷新时，较旧的会话同步结果不会覆盖较新的结果。

Windows 界面的主要快捷键统一显示 Ctrl。中文输入法组合输入期间，Enter 不会触发首页发送或快速查找确认。

## 升级

已经使用 Windows 1.1.0 便携版：使用 1.2.0 更新包，按包内说明替换 app/hermes-desktop.jar。旧 JAR 的备份请放在 app 文件夹之外，避免启动时同时加载两个版本。它沿用 1.1.0 的其余依赖和 Java 运行环境。

首次使用或需要完整目录：完整解压 1.2.0 portable 包，双击 Start-Hermes.bat。不要只复制启动脚本；app 和 runtime 必须一起保留。

数据仍在当前 Windows 用户的 %LOCALAPPDATA%\HermesDesktop。升级不改变用户数据格式和目录。建议保留旧版目录，便于需要时回退。
