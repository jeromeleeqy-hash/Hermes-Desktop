# Hermes Windows 1.3.0 · 体验重构

这一版围绕“切换工作空间、开始对话、跟进执行、继续处理成果”重新组织界面，延续现有网关、项目和数据目录。

## 导航与视觉

- 工作空间与项目筛选合并到左侧导航，支持查找工作空间；收起导航后仍能切换。
- 模型选择移到聊天输入框，支持按模型或提供商搜索。切换中显示状态，完成前暂停发送；延迟返回不会把你带回上一段会话。
- 文件入口在刷新按钮旁，保留目录、近期产物、本机草稿、文档分栏和文件栏拖动调整。
- 重绘 52 个 SVG 图标，统一线条、尺寸和按钮状态。三套主题、深色模式、密度与字号选择继续保留。

## 输入与阅读

- 在“设置 → 对话与记忆”或输入框下方选择 Enter 发送 / Ctrl+Enter 发送。
- Enter 发送时，Shift+Enter 换行；Ctrl+Enter 发送时，Enter 换行。换行保留光标与选区逻辑，输入法组合输入时不触发发送。
- 修整完整发送点击区域，统一键盘和点击的提交入口。附件准备、模型切换、空内容、停止中等状态都有明确反馈。
- 已确认被服务器拒绝的消息恢复为草稿，可直接重试；未知提交结果先恢复状态，避免重复执行。
- 任务运行中可排队、补充指令或停止后发送。只有服务器确认停止后，才提交替代任务；队列可以查看、改写和移除。
- 已知的英文模型切换头转成简短中文记录；等待中断提示结构化显示。原始消息仍保留，引用和代码示例不被删除。
- 助理正文采用轻量阅读布局，执行活动默认折叠，可选择展开或只看回答；大纲可定位已加载的问题。
- 阅读旧消息时保留当前位置；切换会话保留本次运行期间的阅读位置。刷新最近消息时，保留能够与新结果衔接的已加载历史。

## 会话、成果与设置

- 侧边栏按置顶、今天、昨天和更早分组；完整会话页增加置顶、未读、执行中筛选，并提供清除筛选。
- 任务完成项连接原会话和已索引的文件，产物引用随本机完成记录保存。
- 文件根据类型显示图标；文件阅读、编辑、修改对比和未保存草稿流程继续保留。
- 本机输入与阅读选项可独立使用，服务器配置读取失败不会挡住这些设置。
- 提供商目录可以搜索、展开；Skills、工具集、MCP 采用统一状态与详情层次。MCP 已配置、已启用与工具数量分别呈现。
- 网关诊断分别检查 HTTP、登录、实时连接、会话读取和文件能力，显示各项结果并支持复制诊断。
- 保留 1.2.1 的会话分页修复：每页最多 100 条，空页正确结束，后续页失败保留已加载内容。

## 使用与升级

已有 Windows 1.2.0 / 1.2.1 便携版：关闭 Hermes，将旧的 `app/hermes-desktop.jar` 备份到 app 目录外，再用更新包同名文件替换。其余 66 个依赖逐字节核对一致。

首次使用或希望直接解压运行：使用完整 portable 包，完整解压后双击 `Start-Hermes.bat`。已包含 Windows x64 Java 21，无需自行安装 Java。

本机数据继续使用 `%LOCALAPPDATA%\HermesDesktop`，不需要清除登录状态或草稿。源码包包含源码、构建脚本、图标生成脚本、测试与验证记录。

## 验证范围

自动化测试 151 项：149 项通过，2 项 Windows DPAPI 原生测试因平台条件跳过。新增 9 项使用真实 Compose 组件、鼠标/键盘事件、控制器和本地 WebSocket 网关验证发送、重试、排队、停止和模型切换。

界面截图来自实际 Compose 渲染与演示数据，覆盖三种主题、深色、窄窗口、分栏与常见缩放比例。构建与测试在 Linux 完成，尚未在 Windows 真机或你的生产网关执行本包。语音、麦克风、通知、DPAPI 和 JavaFX 原生窗口仍需实际 Windows 环境确认。
