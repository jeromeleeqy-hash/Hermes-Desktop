# 與 Android 3.6.5 的功能對齊

版本：1.0.0-beta.3。使用者已確認前版可以編譯、連線閘道並使用基礎功能。本版最佳化桌面佈局，新增互動仍需按真機步驟複核。

| 功能 | 本版實現 | 具體邊界 |
| --- | --- | --- |
| 登入、Profile、專案 | 複用原登入與專案協議；各 Profile 獨立用戶端；記住專案選擇 | Keychain、伺服器許可權需真機確認 |
| 對話管理 | 新建、固定日常助理、重新命名、AI 標題、置頂、歸檔、恢復、專案移動、刪除 | 移動端觸控操作對映為桌面選單 |
| 歷史與搜尋 | 歷史分頁、專案／時間篩選、內容搜尋、命中訊息定位 | 搜尋最近最多 100 個對話，每個最近 200 條訊息 |
| 聊天渲染 | Markdown、程式碼、表格、圖片、推理展開、複製、引用來源 | 流式期間先顯示文字，結束後排版 |
| 命令與提示詞 | 分類／搜尋伺服器命令；提示詞增刪改、排序、恢復預設、填入草稿 | 填入後由使用者決定傳送 |
| 附件 | 本機圖片／文本、拖入、伺服器檔案路徑、隨草稿持久化 | 沿用手機版的數量與大小限制 |
| 執行與佇列 | 多對話隔離、工具進度、追加要求、排隊、停止、完成記錄 | 恢復後的佇列需要顯式繼續 |
| 斷線／重啟恢復 | 提交前持久化執行標識、原問題與附件；取回伺服器後續回覆；不自動重發 | 伺服器訊息不足以確認結果時繼續保留恢復狀態 |
| 審批／澄清 | 伺服器端選項、單選／多選／自由輸入、響應中狀態、持久化、來源跳轉 | 過期記錄可手動移出；不會替使用者作答 |
| 專家會審 | 快速 MoA、深度真實子 Agent、真實專家返回展開 | 依賴伺服器配置和委派工具；提示詞約束工具不可用時明確降級 |
| 定時任務 | 列表、詳情、新建／編輯、暫停／恢復、立即執行、刪除 | Cron 表示式與時區由伺服器端解釋 |
| 檔案瀏覽 | 可收起右側欄、目錄、路徑、檔名搜尋、最近產物、來源定位 | 搜尋範圍為當前目錄，不宣稱全伺服器全文搜尋 |
| 文件編輯 | 多標籤、預覽／富文本／原始碼、未儲存草稿、重啟恢復、儲存／下載 | 複雜 Markdown 預設原始碼；伺服器沒有原子條件寫入 |
| 圖片／PDF／HTML | 圖片縮放、PDF 分頁渲染與錯誤提示、靜態 HTML 預覽 | HTML 禁止指令碼與遠端資源，不作為通用瀏覽器 |
| MEMORY／SOUL | 當前 Profile 檔案讀取、預覽與編輯 | 保持原伺服器端內容與路徑規則 |
| 單次語音 | WAV 錄音、伺服器／系統識別、中文簡繁轉換、回填／自動傳送、失敗錄音重試 | 錄音繫結開始時的對話；Mac 硬體及授權待測 |
| 連續語音 | 自動判斷停頓、噪聲適應、60 秒錄音上限、分段朗讀、語速、打斷、繼續聆聽 | 原生 Speech 輔助程式需 Apple Command Line Tools 編譯；無元件時使用伺服器 |
| 模型與對話設定 | 預設、對話、輔助、備用模型、推理、上下文、MoA、自定義服務商、人格和時區 | 模型可用性取決於伺服器實際配置 |
| 記憶與審批設定 | 記憶／檔案開關及上限、壓縮閾值與目標、保護訊息數、審批模式／超時 | 數值範圍沿用伺服器端約束 |
| Skills／工具／MCP | 讀取、Skill 內容、啟停 | 伺服器端未提供的管理介面不在用戶端虛構 |
| Agent 更新 | 檢查、提交官方更新介面、進度與日誌、重新連線 | 更新前在介面確認並結束執行任務；未呼叫使用者真實伺服器 |
| 個性化 | 獨立頭像裁剪、暱稱、助理名、簡介、人物動畫、減少動態 | 桌面採用現有佈局，三種主題使用不同色調與側欄漸變，未使用 Apple 原生 Liquid Glass API |
| 語言 | 中英文介面切換、系統語言選擇、協議文案切換 | 伺服器返回的內容、使用者文本和部分錯誤詳情保留原文 |
| 桌面能力 | 選單、快捷鍵、視窗尺寸記憶、檔案拖入、剪貼簿、通知、Dock 標記 | 麥克風、系統識別、通知與打包身份需在 Mac 確認 |

Android 的系統分享入口、震動、返回手勢等不照搬；桌面用拖入檔案、系統通知、選單和鍵盤完成相應操作。完整業務流程已經實現，正式釋出仍以真實閘道和 Mac 驗收結果為準。
