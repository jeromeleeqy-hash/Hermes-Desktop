# Hermes Windows 1.6.0 · 桌面與文件體驗

## 視窗與圖示

- F1 清爽插畫作為桌面應用圖示，保留原始角色設計；應用圖示與個人/助理頭像獨立。PNG 保留透明圓角，ICO 包含 16/20/24/32/40/48/64/96/128/256 畫素。
- 拖動改為 AWT 螢幕座標事件，避免移動視窗時區域性座標變化造成拖不動。完整雙擊只切換一次最大化，按鈕區域不參與拖動。
- 最大化設定當前顯示器工作區，並通過 WM_GETMINMAXINFO 設定原生邊界，覆蓋多顯示器和工作列位於不同邊緣的情況。保留 Windows 11 DWM 圓角及 Windows 10 回退。

## 頭像與互動

- 圖片選擇器綁定當前頭像彈窗，支援直接點選頭像選圖；解碼、裁剪、儲存移到後臺，增加處理中與錯誤反饋。支援 PNG/JPEG/GIF/BMP/WebP。
- 頁面切換改為短位移、快速減速的淡入，減少突然閃空；懸停與按下反饋縮短起始延遲。仍遵循減少動效設定。

## Markdown

- 回車自動續寫無序、有序、任務列表及引用；空列表回車退出；程式碼塊與輸入法組詞不觸發列表續寫。
- 標題級別、刪除線、格式再次點選取消、查詢替換（可撤銷）、文件內圖片預覽與相對連結/錨點。
- 後臺解析、只繪製可見行號、游標跟隨取消逐鍵滾動動畫，減少長文件編輯抖動。保留原始碼、雙欄、草稿、修改對比和儲存前伺服器衝突檢查。

## 檔案預覽

- 圖片：適應視窗、1:1、縮放、拖動平移、旋轉與畫素尺寸。
- PDF：單次開啟文件、逐頁繪製、跳頁、縮圖、加密檔案密碼輸入。
- Word（doc/docx）：段落、標題、強調、嵌入圖片、表格閱讀與縮放。
- Excel（xls/xlsx）：切換工作表、數字格式、已儲存公式結果、合併單元格、每批 100 行/30 列與固定表頭。
- PPT（ppt/pptx）：幻燈片繪製、縮圖、跳頁和縮放。
- 網頁（html/htm）：工作空間相對圖片和 CSS 打包到內嵌瀏覽器，外部連結交給系統瀏覽器。

Office 預覽不執行宏或外部公式，也不承諾復現全部 Office 字型、複雜排版、圖表和動畫。網頁不執行指令碼、不自動讀取外部資源。

## 升級

新增 Apache POI 與更新後的 PDF 依賴。安裝包自動更換應用依賴；便攜更新包必須整體替換 app 目錄。配置和草稿目錄保持原有位置。

實現參考：[Windows 最大化邊界](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-getminmaxinfo)、[Apache POI](https://poi.apache.org/)、[PDFBox](https://pdfbox.apache.org/download.html)、[jsoup](https://jsoup.org/download)。驗證證據見 WINDOWS-VALIDATION.md。
