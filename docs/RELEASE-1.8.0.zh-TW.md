# Hermes Windows 1.8.0

本輪使用已選定的 C1 圖示，集中處理檔案預覽、後臺執行和桌面快捷提問。

## 檔案預覽

- Word（DOC / DOCX）與 Excel（XLS / XLSX）增加獨立的本機相容渲染器，網頁元件啟動失敗不會再讓這兩類檔案整頁空白。保留正文、表格、工作表切換、分頁、合併單元格及常見嵌入圖片。
- HTML 繼續使用隔離的靜態網頁預覽；網頁元件不可用時自動顯示相容預覽，可重新嘗試網頁元件或檢視原始碼。
- Windows 啟動指令碼明確裝載 JavaFX 模組，預覽初始化錯誤寫入啟動日誌，便於定位執行環境問題。
- 修正文件嵌入視窗時可能被繪製層遮擋的問題，相容使用軟體渲染的電腦。
- PPT / PPTX / PDF 支援翻頁、縮圖、縮放及文字閱讀；頁面排版失敗時顯示可提取的文字。
- Office 為只讀預覽。複雜圖表、嵌入物件、特殊字型、幻燈片動畫和部分舊文件排版可能與 Office 原軟體不同；保留下載入口。HTML 預覽不執行頁面指令碼。

## 後臺與托盤

- 點選主視窗右上角關閉按鈕，會收起到系統托盤，任務、回覆接收和草稿儲存繼續工作。
- 左鍵點選托盤圖示恢復主視窗；右鍵選單可以開啟主視窗、切換懸浮球，或選擇“退出 Hermes”完整退出。
- 系統托盤不可用時，關閉按鈕退回為最小化，避免視窗消失後無法找回。
- 升級和解除安裝前，請通過托盤選單完整退出。

## 桌面懸浮球

- 與軟體使用同一 C1 圖示，位於普通桌面視窗之上，拖動後記住位置。
- 單擊開啟獨立提問小窗，每次新開啟預設進入“日常助理”；小窗可以搜尋和切換對話。
- 拖入檔案後加入當前小窗對話的附件草稿，輸入問題後傳送。也支援檔案選擇和貼上附件。
- 雙擊進入框選截圖。拖動選擇範圍，鬆開後加入附件；Esc 或右鍵取消。
- 長按左鍵進入連續語音對話。識別結果發給小窗所選對話，沿用已有語音識別與朗讀配置；介面顯示錄音、識別、回應和朗讀狀態。
- 文字、檔案、截圖和語音繫結到小窗對話，不會因主視窗停在另一個對話而誤發。
- 單擊、雙擊、長按與移動共用手勢判定；加入懸停、縮放、檔案拖入高亮及語音呼吸動畫，並尊重“減少動態效果”設定。
- 設定 → 桌面助手，可以即時開關懸浮球。
- 關閉小窗保留草稿和任務；關閉連續語音會停止繼續聆聽。

## 安裝與更新

推薦直接使用 `Hermes-Windows-1.8.0-Setup.exe`。已有安裝可在完全退出舊版後升級，使用者配置、頭像與草稿儲存在原使用者資料目錄。

便攜版需要完整解壓後執行 `Hermes.exe`。更新包必須替換整個 `app` 目錄以及本包的 `Hermes.exe`、`Start-Hermes.bat` 和 `Diagnose-Hermes.bat`，保留已有 Windows Java 21 `runtime`。只覆蓋主 JAR 或沿用舊啟動指令碼不構成完整升級。

## 驗證說明

構建環境為 Linux。自動測試、真實文件渲染及桌面小窗驗證記錄見 `WINDOWS-VALIDATION.md`。Windows 托盤、系統麥克風、真實多屏 DPI 與真實閘道仍需要在 Windows 電腦上驗收；安裝包未進行 Windows 程式碼簽名。
