# Hermes Desktop 2.0.2

## 對話同步與未讀

- 讀取最新訊息前核對伺服器訊息數量，避免長對話按舊偏移量一直讀到舊訊息。
- 停留聊天頁時每 5 秒核對訊息；返回視窗和手動重新整理立即核對。前臺對話列表每 15 秒重新整理。
- 保留已載入的歷史、輸入草稿和附件；舊請求不能覆蓋正在生成的回覆，失敗時保留已顯示內容並允許恢復。
- 未讀數量按當前工作空間、專案和普通對話統計，排除隱藏後臺任務和已移除對話。列表顯示明確的“未讀”標記；成功讀到訊息後清除。
- 儲存已讀訊息數量，用於識別其他裝置新增的訊息。

## 桌面工作台與導航

- 普通啟動預設進入簡潔工作台，同時保留上次對話和草稿。
- “值得留意的事”是工作台中的獨立模組，點選檢視全部，明確返回工作台。
- 去掉桌面端兩種首頁模式切換；事項整理、同步、早晚安排放在模組內部。
- 側欄最近對話從 4 個增加到 8 個，置頂優先，空間不足時滾動。

## macOS 通知

- 使用 Hermes.app 自身的 UserNotifications 通知中心，不再呼叫 osascript。
- 點選回覆或待確認通知開啟 Hermes 和對應對話；首頁通知開啟工作台。
- 跳轉保留工作空間與對話 ID，支援啟動連線完成後繼續跳轉，並防止舊賬號通知跳入其他連線。
- 首次傳送時由 macOS 請求 Hermes 通知許可權。

繼承 2.0.1 的確認面板佈局、取消逐條“已傳送”提示、卡片排版和本機 TTS/STT 修復。

構建環境為 Linux；Mac 原生通知展示/點選和 Windows 原生執行需在對應系統驗收，不能由跨平臺自動化代替。
