# Hermes Desktop 2.0.3 构建说明

沿用 2.0.2 的 JDK 21、Gradle 8.13、Kotlin 2.3.20 和 Compose Desktop 1.10.1 依赖。应用 JAR 由当前源码重新编译。

- 运行路径解析、真实 HTTP 文件读取、历史卡片恢复、工作空间恢复和桌面交互相关测试。
- 以 SHA-256 验证 2.0.2 安装包和依赖清单；依赖声明未改变后复用各平台依赖与原生运行时。
- 重新构建 Windows 原生启动器与 NSIS 安装器；安装器使用同一份已校验便携包。
- Mac 替换应用 JAR 与版本信息，重新进行 ad-hoc 签名，校验资源封装、代码页和归档执行权限。

构建及包结构校验不能代替 Windows / macOS 真机验证。
